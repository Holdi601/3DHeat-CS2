# Табела топлотне мапе (`<match>.parquet`) {#the-heatmap-table-parquet}

Један Parquet фајл по мечу: положај сваког живог играча, узорковано, и сваки догађај тамо где се десио, по један ред - дуга табела коју приказивач 3DHeat чита као топлотну мапу, а све остало као обичну табелу. Код: [`heat3d_cs2/output.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/output.py) (фајл), [`heat3d_cs2/match.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/match.py) (редови; видите [Како се прави меч](building-matches.md)).

Фајл се пише са Snappy компресијом у групама редова од 256.000 редова. Редови су сортирани по `time`, па по `event`. У њој су само редови унутар рунде (од краја њеног замрзавања до почетка следеће рунде).

На синтетичком демоу из тестова, редови догађаја прве рунде:

![редови догађаја у табели](../assets/img/table-rows.svg)

У `.3dheat` контејнеру табела је члан са улогом `table` ([Једна датотека по мечу](output-container.md)).

## Колоне {#columns}

Колоне, увек овим редом. Текстуалне колоне су стрингови кодовани речником (`dictionary<int32, string>`) и никад нису null: "нема вредности" је празан стринг. Бројчане колоне су null где ред нема вредност.

| Колона | Тип | Шта |
|---|---|---|
| `match` | стринг | име меча (`alpha-vs-bravo-m1`, или `...-b` за други ланац) |
| `map` | стринг | мапа, из заглавља демоа (`de_x`) |
| `round` | int16 | број рунде, од 1 |
| `roundId` | стринг | `<match> #NN`, број рунде у две цифре (`alpha-vs-bravo-m1 #07`): јединствен у свим мечевима, сесија приказивача |
| `phase` | стринг | `freeze` у времену замрзавања рунде (од краја претходне рунде), `live` док рунда није одлучена, `after` док победници лове а губитници штеде |
| `time` | float64 | секунде од почетка меча (живог почетка његове прве датотеке), на једном сату преко свих његових датотека |
| `roundTime` | float32 | секунде од краја замрзавања ове рунде; негативно у времену замрзавања |
| `event` | стринг | шта ред јесте - видите [Догађаји](#догађаји) |
| `player` | стринг | име играча (за сваки догађај, који играч је наведен испод) |
| `steamid` | стринг | Steam ID играча (64-битни, као текст) |
| `side` | стринг | `T` или `CT` у овој рунди; празно кад играч није био ни на једној страни |
| `team` | стринг | назив тима играча (или `Started T` / `Started CT`); за `explode`, тим који је поставио бомбу |
| `x`, `y`, `z` | float32 | положај у игриним координатама: инчи (јединице игре), **Z нагоре**, десноруки |
| `dirX`, `dirY`, `dirZ` | float32 | куда играч гледа, јединични вектор у истом систему; само положаји |
| `health` | int16 | 0-100; положаји, а код `hurt` шта је остало после поготка |
| `armor` | int16 | 0-100; положаји, а код `hurt` шта је остало после поготка |
| `money` | int32 | новац играча; само положаји |
| `equipment` | int32 | вредност онога што играч носи; само положаји |
| `weapon` | стринг | оружје како га игра именује (`AK-47`, `M4A1-S`, `Knife` за сваки скин ножа) |
| `place` | стринг | назив места на мапи на положају реда (`BombsiteA`, `CTSpawn`); празно код експлозија бацача: демо не именује место где је бацач експлодирао |
| `throwerPlace` | стринг | назив места бацача кад је бацач експлодирао; само експлозије бацача |
| `other` | стринг | други играч код убиства, смрти, поготка или блица |
| `damage` | float32 | изгубљено здравље; само `hurt` |
| `duration` | float32 | секунде ослепљености; само `blind` |
| `headshot` | int8 | 0/1; само `kill` и `death` |
| `opening` | int8 | 0/1, прво убиство непријатеља у рунди; само `kill` и `death` |
| `traded` | int8 | 0/1. За `kill`: било је убиство које је осветлило саиграча. За `death`: смрт која је осветљена у року од 5 s. Само `kill` и `death`. |
| `noscope` | int8 | 0/1, убиство оружјем са нишаном испаљеним без нишана (`noscope` догађаја); само `kill` и `death` |
| `attackerBlind` | int8 | 0/1, убица је био ослепљен кад је убио (`attackerblind` догађаја); само `kill` и `death` |
| `won` | int8 | 0/1, да ли је страна овог реда победила рунду; null кад је `side` празно |
| `matchWon` | int8 | 0/1, да ли је тим овог реда победио меч; null кад је `team` празно или снимак не показује крај (видите `winner` у документу меча) |
| `roundEndReason` | стринг | како се рунда реда завршила: `elimination`, `bomb` (бомба је експлодирала), `defuse`, `time`, `surrender`, `draw`, `other` |
| `buy` | стринг | куповина стране овог реда у овој рунди: `pistol`, `eco`, `force`, `full` |
| `detail` | стринг | сва поља догађаја која остале колоне не носе, као JSON објекат (игрина сопствена имена): пуцањ `fire_bullets` (порекло, углови, нетачност, раширеност, индекс трзаја, семе...), `dominated`, `revenge`, `attackerinair`, `wipe`... смрти, `defindex` предмета, корак ништа |
| `text` | стринг | ред ћаскања; само `chat` |
| `entity` | int32 | ентитет бацача: лет `throw` (редови `grenade`), његова експлозија и играчи које је ослепео деле га |
| `hitgroup` | стринг | где је метак погодио (`head`, `chest`, ...); `hurt`, `kill`, `death` |
| `armorDamage` | int16 | изгубљен оклоп; само `hurt` |
| `hitLocalX`, `hitLocalY`, `hitLocalZ` | float32 | где је на телу метак погодио, у оквиру жртве у метрима (x напред, y уз стопала, z десно): зрак пуцња (`fire_bullets`, иначе очи нападача и поглед) праћен до тела постављеног као што је жртва стајала и чучала, до дела који `hitgroup` именује; само `hurt` |
| `hitDirX`, `hitDirY`, `hitDirZ` | float32 | смер пуцња у истом оквиру; `hitMiss` колико (m) је зрак промашио именовани део (0: прошао кроз њега); `hitFrom` `bullet` или `aim` |
| `penetrated` | int16 | зидови кроз које је прошао метак који је убио; `kill` и `death` |
| `throughSmoke` | int8 | 0/1, убијен кроз дим; `kill` и `death` |
| `distance` | float32 | даљина убиства како је игра рачуна (метри); `kill` и `death` |
| `assister` | стринг | ко је асистирао; `kill` и `death` |
| `flash`, `flashAlpha` | float32 | секунде блица који је остао, и колико је бео; положаји |
| `helmet`, `defuser`, `scoped`, `walking`, `airborne`, `buyZone`, `bombZone`, `defusing`, `spotted` | int8 | 0/1; положаји |
| `zoom`, `duck`, `moveType` | | ниво зума нишана, колико је чучао (0-1), игрин тип кретања; положаји |
| `spottedBy` | стринг | Steam ID-јеви непријатеља који виде овог играча, одвојени са `\|`; положаји |
| `inventory` | стринг | све што играч носи, одвојено са `\|`; положаји |
| `ammo`, `ammoReserve`, `shotsFired` | int16 | магацин и резерва оружја у руци; испаљени меци у рафалу; положаји |
| `punchPitch`, `punchYaw` | float32 | удар трзаја у нишану, степени; положаји |
| `ping` | int16 | милисекунде; положаји |
| `killsTotal`, `deathsTotal`, `assistsTotal`, `headshotKillsTotal`, `damageTotal`, `utilityDamageTotal`, `enemiesFlashedTotal`, `objectiveTotal`, `aceRoundsTotal`, `threeKillRoundsTotal`, `aliveTimeTotal`, `moneySavedTotal`, `mvps`, `score` | int | игрини сопствени бројеви табеле резултата за меч до сада; положаји |
| `cashSpent`, `cashSpentTotal`, `roundStartEquipment` | int32 | новац потрошен у овој рунди и у мечу; вредност опреме кад је рунда почела; положаји |
| `state_helmet`, `state_defuser`, `state_kevlar`, `state_scoped`, `state_flashed` | int8 | 0/1, стање играча у времену реда, укључујући догађаје: шлем, комплет за деактивирање, било који оклоп, нишан (од последњег узорка положаја играча до реда), блицован (унутар `blind` који га је погодио); сваки ред који именује играча |
| `state_utility` | int16 | бацачи које носи у том времену (из `inventory`); сваки ред који именује играча |
| `state_weapon` | стринг | оружје у руци у том времену (код `death`, жртвино сопствено, где је `weapon` убицино); сваки ред који именује играча |
| `earn_round_cs2` | int16 | колико је рунда исплатила: на `round_end` награда за победу или бонус за пораз (са бонусом стране која је поставила бомбу), на `plant` и `defuse` 300 играча |

## Догађаји {#events}

Који играч ред именује, где стоји, и које колоне попуњава. `match`, `map`, `round`, `roundId`, `phase`, `time`, `roundTime`, `event`, `won`, `roundEndReason` и `buy` су попуњени на сваком реду (`matchWon` где је познат победник меча); `inventory`, `money`, `equipment` и колоне `state_*` на сваком реду који именује играча (догађаји их узимају из последњег узорка положаја играча).

| `event` | `player` / `side` / `team` | `x`, `y`, `z` | Такође попуњено |
|---|---|---|---|
| `position` | играч | играч (стопала) | `dirX`-`dirZ`, `health`, `armor`, `money`, `equipment`, `weapon` (у руци), `place`, и целокупно стање играча (колоне од `flash` надаље) - и у времену замрзавања |
| `kill` | убица | где је убица стајао | `other` (жртва), `weapon`, `headshot`, `opening`, `traded` (убиство које је осветлило), `noscope`, `attackerBlind`, `place` |
| `death` | жртва | где је жртва пала | `other` (убица; празно за свет), `weapon`, `headshot`, `opening`, `traded` (осветљена), `noscope`, `attackerBlind`, `place` |
| `hurt` | жртва | где је жртва погођена | `other` (нападач), `damage`, `health`, `armor`, `armorDamage`, `hitgroup`, `weapon`, `place` - и погоци саиграча и света |
| `shot` | пуцач | одакле је пуцано | `weapon`, `place`, `detail` (игрин опис метака) |
| `slash` | играч | где је замахнут нож | `weapon` = `Knife` |
| `grenade` | бацач | бацач у лету, на узорковању играча и где је стао | `weapon` (бацач), `entity` |
| `throw` | бацач | одакле је бацач бачен | `weapon` (бацач), `place` |
| `smoke`, `flash`, `he`, `molotov`, `decoy` | бацач | где је експлодирао | `weapon`, `throwerPlace` (место бацача у том тренутку); `place` остаје празно |
| `blind` | играч ослепљен блицем | где је стајао | `other` (блицер), `duration`, `weapon` = `Flashbang`, `entity`, `place` - ослепљени саиграчи такође |
| `plant` | постављач | где је поставио | `weapon` = `C4 Explosive`, `place`, `earn_round_cs2` (300) |
| `defuse` | деактиватор | где је деактивирао | `weapon` = `C4 Explosive`, `place`, `earn_round_cs2` (300) |
| `round_end` | сваки играч који је одиграо рунду | где је играч последњи стајао | `won`, `earn_round_cs2` (колико му је рунда исплатила: раст новца стране до следећег замрзавања где правила то дозвољавају, иначе правилима предвиђено), `detail` (`winner`, `reason`, `lossBonus`, `plant`) |
| `explode` | постављач (са својим Steam ID-јем), страна `T`, тим који је поставио | положај постављања | `weapon` = `C4 Explosive`, `place` (постављачево при постављању: где је бомба лежала); његово време је кад је бомба експлодирала |
| `chat` | пошиљалац | где је био | `text` |
| сваки други догађај игре о играчу, под игриним називом: `item_pickup`, `item_equip`, `player_footstep`, `player_jump`, `weapon_reload`, `weapon_zoom`, `player_spawn`, `bomb_beginplant`, `bomb_begindefuse`, `bomb_dropped`, `bomb_pickup`, `bomb_exploded`, `smokegrenade_expired`, `inferno_expire`, `decoy_started`, `player_team`, `player_disconnect`, ... | играч | где је био (догађаји бацача: где је бацач био) | `weapon` (предмета), `entity`, `detail` (сва поља догађаја) |

Шта јесте а шта није у табели:

- Редови **position** су живи играчи на страни, ван времена замрзавања и загревања, на сваких `--every` тактова (осам у секунди подразумевано).
- Редови **kill** су убиства само од непријатеља - без тимских убистава, самоубистава или смрти од света. Редови **death** су свака смрт, укључујући те.
- Редови **explode** су свака постављена бомба која је експлодирала, по `bomb_exploded` демоа: и у после фази, кад су T већ победили елиминацијом. Демо без тог догађаја добија по један за сваку рунду коју је победила бомба, на крају рунде.
- Редови **hurt** и **blind** су само између непријатеља.
- **shot** изоставља ножеве и C4; бацачи су редови **throw**.
- **molotov** обухвата молотове и запаљиве бомбе (почетак ватре).
- Штета саиграча, блицеви саиграча и гледалаца, догађаји у времену замрзавања и све између рунди нису у табели.

Радни пример, из синтетичког демоа из тестова (бачен дим, отварајуће убиство у главу, размене):

| time | roundTime | event | player | side | x | y | weapon | other | damage | headshot | opening | traded |

| 18.75 | 8.75 | throw | ash | T | 120 | 10 | Smoke Grenade | | | | | |
| 19.84 | 9.84 | hurt | bob | CT | -500 | -300 | AK-47 | ace | 60 | | | |
| 20.00 | 10.00 | death | bob | CT | -500 | -300 | AK-47 | ace | | 1 | 1 | 1 |
| 20.00 | 10.00 | hurt | bob | CT | -500 | -300 | AK-47 | ace | 40 | | | |
| 20.00 | 10.00 | kill | ace | T | 100 | 0 | AK-47 | bob | | 1 | 1 | 0 |

| 21.88 | 11.88 | death | ace | T | 100 | 0 | AK-47 | ben | | 0 | 0 | 1 |

## Наговештаји заглавља `heat3d` {#the-heat3d-footer-hints}

Parquet заглавље фајла (метаподаци кључ/вредност шеме) носи упутства за читање под кључем **`heat3d`**, JSON објектом:

```json
{
  "version": 1,
  "kind": "cs2-demo",
  "axes": {"up": "z", "flipX": false, "flipY": true, "flipZ": false, "scale": 1},
  "entity": {"size": 32},
  "columns": {
    "x": "x", "y": "y", "z": "z",
    "time": "time", "timeUnit": "seconds",
    "personId": "player",
    "teamId": "side",
    "sessionId": "roundId",
    "lookMode": "vector", "dirX": "dirX", "dirY": "dirY", "dirZ": "dirZ",
    "extra": ["event", "match", "round", "roundTime", "phase", "weapon", "place", "won", "matchWon", "roundEndReason", "buy", "opening", "team", ...]
  }
}
```

| Ставка | Каже |
|---|---|
| `version`, `kind` | верзија наговештаја (1) и шта их је написало (`cs2-demo`) |
| `axes.up` | Z фајла је нагоре |
| `axes.flipY` | негирај Y фајла (видите испод) |
| `axes.scale` | 1: положаји се користе како јесу, у игриним јединицама |
| `entity.size` | играч је **32 јединице** широк - ширина CS2 играча - величина коју кутија реплеја црта за једног |
| `columns.x` / `y` / `z` | колоне положаја |
| `columns.time`, `timeUnit` | `time`, у секундама |
| `columns.personId` | играч је особа |
| `columns.teamId` | страна је група (па T и CT, а не називи тимова, боје групе) |
| `columns.sessionId` | свака рунда (`roundId`) је сесија |
| `columns.lookMode` и `dirX`-`dirZ` | смер погледа је вектор у тим колонама |
| `columns.extra` | колоне које се задржавају као филтри, по корисности |

Приказивач који зна кључ отвара фајл без иједног подешавања. Све остало га игнорише. Да га сами прочитате:

```python
import json
import pyarrow.parquet as pq

table = pq.read_table("out/de_x/alpha-vs-bravo-m1.parquet")
hints = json.loads(table.schema.metadata[b"heat3d"])
rows = table.to_pandas()
kills = rows[rows["event"] == "kill"]
```

## Осе и јединице {#axes-and-units}

Координате су игрине сопствене: **инчи** (једна јединица игре; играч је 72 јединице висок кад стоји и 32 широк), **Z нагоре**, и десноруке.

Приказивач чији је свет са Y нагоре мора да црта игрине (x, y, z) као **(x, z, -y)** - Z постаје висина, а Y се негира. То је ротација, не огледало. Нацртано онако како се црта леворуки свет са Z нагоре, као (x, z, y), свака мапа излази пресликана, A сајт на погрешној страни; `flipY: true` је оно што наговештаји кажу да се спречи. [Извоз мапе](map-export.md) већ пише своју геометрију у оквиру (x, z, -y), у истим јединицама, па лежи испод табеле без икаквог прилагођавања.

Даљине у приказивачу су означене у метрима; са размером 1 то су игрине јединице. Помножите са 0,0254 за метре.

## Величина {#size}

Положаји доминирају: око десет играча пута 8 узорака у секунди живе игре при подразумеваном `--every 8`, мање за мртве играче и време замрзавања. Преполовљавање `--every` удвостручује их; догађаји се не мењају.
