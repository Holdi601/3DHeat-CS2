# Статистика {#statistics}

Шта је сваки играч урадио у мечу, и како је сваки рунда текла: табела резултата и листа рунди [документа меча](output-match-json.md). Код: [`heat3d_cs2/stats.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/stats.py). Све се броји из меча направљеног као на [Како се прави меч](building-matches.md): његови записи убистава, његова штета (изгубљено здравље, само непријатељи), његови блицеви (само непријатељи) и његови редови.

![текстуална табела резултата синтетичког меча](../assets/img/scoreboard.svg)

## Конвенције {#the-conventions}

Где сама игра не дефинише број, ово су дефиниције. Оне су уписане и у сваки документ меча, под `conventions`.

| Појам | Дефиниција |
|---|---|
| **Размена** | Смрт је *размењена* кад њеног убицу убије један од саиграча жртве у року од **5 s**; то убиство је *размена*. |
| **Отварање** | Прво убиство непријатеља у рунди док је жива. Тимско убиство, самоубиство или смрт од света пре њега се прескаче. |
| **KAST** | Удео рунди у којима је играч имао **K**ill (убиство), **A**ssist (асистенцију; асистенција блицем се рачуна), **S**urvived (преживео) или био **T**raded (размењен). |
| **Штета** | Здравље стварно изгубљено, само непријатељи: погодак у главу од 137 на играчу са 40 здравља је 40. |
| **Клач** | Бити последњи жив на страни док још има живих непријатеља; освојен кад страна победи рунду. |
| **Куповина** | По страни, од просечне вредности опреме на крају замрзавања: прва рунда сваке редовне половине је пистол-рунда (рунда 1, и рунда после половине, ако је меч играо њу), продужетак нема; затим испод $1.500 eco, испод $4.000 force, иначе full. |

## Ко је почео сваку рунду {#who-started-each-round}

Неколико бројева мора да зна ко је одиграо рунду. Почетни играчи рунде су, по страни, сваки играч са живим редом положаја у року од једне секунде од најранијег положаја те рунде (то јест, у првој секунди после краја замрзавања). Број **одиграних рунди** играча је број рунди које је започео. Ако није започео ниједну (нема такав ред), узима се број рунди меча, да не би било дељења нулом.

## Ред табеле резултата {#the-scoreboard-line}

Један унос по играчу (видите [документ меча](output-match-json.md#играчи) за називе поља). "Убиство од непријатеља" испод значи убиство с нападачем, а не тимско убиство и не самоубиство (сопствено).

| Поље | Броји |
|---|---|
| `kills` | убиства од непријатеља, и у живој и у после фази |
| `deaths` | свака смрт: од непријатеља, саиграча, себе или света |
| `assists` | убиства од непријатеља која је овај играч асистирао без блица (асистент не сме бити убица) |
| `flashAssists` | убиства од непријатеља која је овај играч асистирао блицем |
| `diff` | убиства - смрти |
| `adr` | штета (изгубљено здравље, само непријатељи, обе фазе) / одигране рунде, једна децимала |
| `kast` | 100 x (рунде са убиством, асистенцијом или асистенцијом блицем, преживљавањем или размењеном смрћу) / одигране рунде, једна децимала. *Преживљавање* је: почетни играч рунде који није погинуо у њој, у било којој фази. |
| `headshotPct` | 100 x убиства у главу / убиства, једна децимала; 0 без убистава |
| `openingKills`, `openingDeaths` | добијени и изгубљени отварајући дуели |
| `tradeKills` | убиства која су осветлила смрт саиграча |
| `tradedDeaths` | смрти које су осветљене |
| `multiKills` | рунде са 2, 3, 4 и 5 убистава од непријатеља (`2k`, `3k`, `4k`, `5k`); више од пет се рачуна као `5k`. Обе фазе се рачунају. |
| `clutches`, `clutchesWon` | одиграни и освојени клачеви (испод) |
| `utilityDamage` | штета нанета HE бацачима, молотовима и запаљивим бомбама, једна децимала |
| `enemiesFlashed` | непријатељи ослепљени најмање **1,0 s** блицевима овог играча |
| `plants`, `defuses` | постављања бомбе и деактивирања (редови табеле) |
| `teamkills` | саиграчи убијени. Самоубиство - нападач и жртва исти играч, рецимо сопствени бацач - није такво: то је само смрт. |
| `roundsPlayed` | почете рунде, како је горе |

Играчи су наведени по називу тима (по абецеди), а унутар тима по `diff`, па по `kills`, најбољи први.

Напомене о ивицама:

- Убиство у после фази - победници који лове играча који штеди - рачуна се као убиство, смрт, за ADR, мултиубиства и KAST као било које друго.
- Wallbang-ови се интерно броје по играчу, али се не пишу у документ меча; свако убиство у листи рунде каже да ли је био такав.
- KAST део *размене* приписује жртви размењене смрти у тој рунди.
- Тимска убиства и самоубиства додају смрт жртви, али никоме не додају убиство; тимско убиство додаје у `teamkills` убице, самоубиство ни у шта друго.

## Клачеви {#clutches}

За сваку рунду, почетни играчи обе стране узимају се као живи, и живи убиства рунде се обилазе редом. После сваке смрти жртва се уклања, и гледа се свака страна: страна на којој је остао тачно **један** играч, и бар један непријатељ је још жив, има клач за тог играча **против** броја непријатеља живих у том тренутку. Сваки играч има највише један клач по рунди; **освојен** је кад страна тог играча победи рунду.

Последице дефиниције:

- Обе стране могу имати клач у једној рунди. Ако једна страна први падне на једног (рецимо 1в3), а затим и друга страна падне на једног, други играч има свој клач 1в1.
- `against` је број кад је играч постао последњи, а не на крају.
- Убиства после фазе се не обилазе, па ни не покрећу ни не мењају клач.

## Преживели {#survivors}

**Преживели** рунде су, по страни, њени почетни играчи минус сви који су погинули док је била жива. Играч убијен у после фази док штеди и даље је преживео у листи рунди - али није *преживео* за KAST.

## Листа рунди {#the-round-list}

Свака рунда у документу меча носи свој исход, резултат, стране, економију, постављање, преживеле, клачеве и своја убиства по реду; видите [Документ меча](output-match-json.md#рунде).

## Текстуална табела резултата {#the-text-scoreboard}

`python -m heat3d_cs2 scoreboard <match.json>` исписује ове бројеве по тиму; видите [Команде](commands.md#scoreboard---меч-као-текст).
