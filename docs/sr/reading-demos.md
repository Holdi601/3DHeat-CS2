# Читање демоа {#reading-a-demo}

Шта се вади из једног `.dem` фајла, пре било каквог тумачења. Код: [`heat3d_cs2/demo.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/demo.py).

CS2 демо је серверов сопствени снимак (SourceTV): сваки играч, сваки такт, 64 такта у секунди (`TICKRATE = 64`). Чита га [demoparser2](https://github.com/LaihoE/demoparser) у три позива, а резултат се чува онакав какав јесте, у `RawPart`:

| Поље | Садржи |
|---|---|
| `path` | фајл |
| `map` | `map_name` из заглавља демоа (`de_x`); празно ако заглавље нема |
| `samples` | један ред по играчу по узоркованом такту: поља играча и правила испод, плус `tick`, `steamid`, `name` |
| `events` | назив догађаја -> његови редови, са пољима играча са префиксима `user_`, `attacker_`, `assister_` како их парсер именује |

Ништа у `demo.py` не одлучује шта је рунда или ко је победио; то је [Како се прави меч](building-matches.md).

## Узорковани тактови {#the-sampled-ticks}

`parse_ticks` се тражи за тактове `0, N, 2N, ...` до 4.000.000 (`LAST_TICK`, далеко преко сваког меча - 17 сати на 64 такта у секунди), где је *N* `--every` (подразумевано 8). Парсер стаје на крају демоа. Сваки играч присутан у узоркованом такту даје један ред, било да је жив, мртав, гледалац или тренер; филтрирање се дешава касније.

Корак узорковања важи и више од густине топлотне мапе: тренутак кад је рунда одлучена чита се из ових узорака (видите [Како се прави меч](building-matches.md#рунде)), па су крајеви рунди тачни до једног корака (1/8 s подразумевано).

### Поља играча {#player-fields}

| Својство | Постаје |
|---|---|
| `X`, `Y`, `Z` | положај, у игриним јединицама (инчи), Z нагоре. demoparser2 даје играчеву тачку ослонца, тј. стопала. |
| `yaw`, `pitch` | смер погледа (степени), претворен у јединични вектор |
| `health`, `armor_value` | здравље, оклоп |
| `team_num` | страна: 2 = T, 3 = CT; све друго (гледаоци, 0, 1) није страна |
| `team_clan_name` | назив тима како га сервер приказује, користи се за именовање тимова |
| `active_weapon_name` | оружје у руци, како га игра именује (`AK-47`, `Karambit`) |
| `is_alive` | да ли је играч жив - само живи играчи постају положаји |
| `last_place_name` | назив места на мапи (`BombsiteA`) |
| `balance` | новац |
| `current_equip_value` | вредност онога што играч носи |

### Поља правила игре {#game-rules-fields}

Читају се уз њих, једном по реду играча (исти су за све у једном такту):

| Својство | За шта се користи |
|---|---|
| `game_time` | серверов сат, у секундама |
| `total_rounds_played` | број рунди, који се наставља преко датотека меча |
| `round_win_status` | ко је победио управо одиграну рунду: 1 нерешено, 2 T, 3 CT |
| `round_win_reason` | како (игрина `CSRoundEndReason`) |
| `team_rounds_total` | резултат сваке стране |
| `is_warmup_period` | загревање се свуда изоставља |
| `is_freeze_period` | време замрзавања се изоставља из положаја |
| `CCSGameRulesProxy.CCSGameRules.m_nOvertimePlaying` | продужетак који се игра, 0 у редовном времену: рунде продужетка нису пистол-рунде (парсер нема краћег назива за то) |

## Догађаји {#the-events}

Сваки догађај испод се чита кад га демо најави (`list_game_events`), с `X`, `Y`, `Z`, `team_num`, `last_place_name` и `which_bomb_zone` (зона бомбе у којој играч стоји: 0 ниједна, 1 A, 2 B) за сваког играча који га догађај именује, и `total_rounds_played` и `is_warmup_period` игре у том такту:

| Догађај | Постаје |
|---|---|
| `player_death` | убиства и смрти; користи `weapon`, `headshot`, `assistedflash`, `penetrated`, `thrusmoke`, `noscope`, `attackerblind` |
| `player_hurt` | штета; користи `dmg_health` (штета нанета здрављу), `health` (остало здравља), `weapon` |
| `player_blind` | ослепљени играчи; користи `blind_duration` |
| `weapon_fire` | пуцњи и бацања; користи `weapon` |
| `smokegrenade_detonate`, `flashbang_detonate`, `hegrenade_detonate`, `inferno_startburn`, `decoy_detonate` | где су бацачи експлодирали; користи сопствене `x`, `y`, `z` догађаја (догађај нема назив места за ту тачку, само бацачево) |
| `bomb_planted` | постављање; користи `which_bomb_zone` и место постављача, и `site` (број ентитета зоне) |
| `bomb_defused` | деактивирање |
| `bomb_exploded` | кад је бомба експлодирала: време реда `explode` |
| `round_freeze_end` | где почиње свака рунда |
| `round_prestart` | где се завршава време после одлучене рунде |
| `round_announce_match_start` | где почиње жив меч |

## Две чињенице о демоима које одлучују како се читају {#two-facts-about-demos-that-decide-how-they-are-read}

- **Меч може бити подељен на више датотека**, а називи датотека не говоре њихов редослед. Број рунди (`total_rounds_played`) се наставља преко њих, и обично серверов сат, па се делови могу поредати према ономе што садрже.
- **Снимак може почети пре меча**: загревање, поновно покретање, рунда ножа. Меч почиње на **последњем** `round_announce_match_start` у датотеци; пре тога се све изоставља, а загревање се свуда изоставља.
