# Συντήρηση αυτών των σελίδων {#maintaining-these-pages}

Η λίστα ελέγχου για κάθε έκδοση. Οι σελίδες πρέπει να λένε τι κάνει ο κώδικας, να διαβάζονται καλά από αρχάριο, από
ένα παιδί οκτώ ετών και από επαγγελματία, και να υπάρχουν σε κάθε γλώσσα που υποστηρίζει ο προβολέας του 3DHeat.

## Λίστα ελέγχου έκδοσης {#release-checklist}

1. **Ξαναδημιουργήστε τις παραγόμενες σελίδες** από τον κώδικα:

   ```bash
   python tools/gen_docs_reference.py
   for f in tools/diagrams/*.json; do python tools/flow2svg.py $f docs/assets/img/$(basename $f .json).svg; done
   ```

   Πριν από το commit, το ίδιο με `--check` πρέπει να τελειώσει με κωδικό 0:

   ```bash
   python tools/gen_docs_reference.py --check
   ```

2. **Συγκρίνετε τα χαρακτηριστικά από την τελευταία έκδοση.** Το `VERSION` κρατά την έκδοση· η ετικέτα της είναι
   `v<VERSION>`:

   ```bash
   git log --oneline v$(cat VERSION)..HEAD
   ```

   Κάθε νέα εντολή, επιλογή, στήλη, έξοδος ή συμπεριφορά παίρνει μία γραμμή στη σελίδα που την καλύπτει, και μία γραμμή
   στο `CHANGELOG.md` κάτω από το **Docs** που ονομάζει τη σελίδα.

3. **Ανεξάρτητος έλεγχος.** Κάποιος που δεν έγραψε την αλλαγή διαβάζει τις αλλαγμένες σελίδες - μαζί με τα διαγράμματα
   και τις εικόνες - τρεις φορές: ως αρχάριος (δεν έχει χρησιμοποιήσει ποτέ τερματικό), ως παιδί οκτώ ετών (η πρώτη
   παράγραφος λέει, με απλά λόγια, τι είναι και γιατί;) και ως επαγγελματίας (είναι οι σημαίες, οι προεπιλογές και οι
   στήλες ακριβώς αυτά που κάνει ο κώδικας;).

4. **Διορθώστε ό,τι βρήκε ο έλεγχος.** Οι εικόνες μένουν το πολύ περίπου 900 px πλάτος, με κείμενο τουλάχιστον 12 px
   όπως φαίνεται· τα διαγράμματα παράγονται από τα `tools/diagrams/*.json` με το `tools/flow2svg.py`. Τα παραδείγματα
   χρησιμοποιούν μόνο επινοημένα ονόματα (`de_x`, "Demo Valley", `<map>`): ποτέ πραγματικό χάρτη, παίκτη, αναγνωριστικό
   αγώνα ή στοιχείο από πραγματικά αρχεία.

5. **Μεταφράσεις.** Κάθε μεταφρασμένη σελίδα καταγράφει το hash της αγγλικής πηγής από την οποία φτιάχτηκε.
   Μεταφράστε ξανά τις σελίδες των οποίων το hash της αγγλικής πηγής άλλαξε, και κάντε τον έλεγχο κάθε γλώσσας με
   τους ίδιους τρεις τρόπους (απλά, αρχάριος, επαγγελματίας), συμπεριλαμβανομένων των ετικετών των διαγραμμάτων.

6. **Δημοσίευση μόνο μετά από την έγκριση του ιδιοκτήτη.** Κάντε commit τοπικά· ο ιδιοκτήτης αποφασίζει πότε
   δημοσιεύεται.

## Μεταφράσεις: οι εντολές {#translations-the-commands}

Ο ιστότοπος μεταφράζεται στις 40 γλώσσες του προβολέα του 3DHeat: τα αγγλικά βρίσκονται στο `docs/`, κάθε άλλη γλώσσα
στο `docs/<lang>/` με τα ίδια ονόματα αρχείων. Το `tools/docs_i18n.py` κάνει τη λογιστική:

```bash
python tools/docs_i18n.py hashes             # after any English change: record each page's hash
python tools/docs_i18n.py svg-strings        # after any picture change: the labels to translate
python tools/docs_i18n.py status             # per language: current, outdated, missing pages
python tools/docs_i18n.py todo --lang de     # the German pages to (re)translate
python tools/docs_i18n.py svg-build --lang de    # German pictures from docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # stamp the German pages with their English hash
python tools/docs_i18n.py check              # exit 1 when hashes or labels are stale
```

Μεταφράζετε μόνο όσα δείχνει το `todo`: κρατάτε ως έχουν το Markdown, τους συνδέσμους, τον κώδικα και τα ονόματα
αρχείων και στηλών· μεταφράζετε τους τίτλους και τις περιγραφές των εικόνων, και χρησιμοποιείτε τις δικές του λέξεις
του προβολέα του 3DHeat για τα κουμπιά και τα πάνελ του (τα `src/i18n/locales/<lang>/` του). Οι παραγόμενες σελίδες
αναφοράς και οι εικόνες του τερματικού μένουν στα αγγλικά. Στον ιστότοπο, μια παρωχημένη μετάφραση το λέει και
συνδέει την αγγλική σελίδα· μια μεταφραμένη σελίδα που λείπει πέφτει πίσω στα αγγλικά. Το μενού γλωσσών της κεφαλίδας
και η ανακατεύθυνση της αρχικής σελίδας ανάλογα με τη γλώσσα του προγράμματος περιήγησης έρχονται από το
`docs/_includes/`.
