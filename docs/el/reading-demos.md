# Ανάγνωση demo {#reading-a-demo}

Τι βγαίνει από ένα αρχείο `.dem`, πριν ερμηνευτεί οτιδήποτε. Κώδικας:
[`heat3d_cs2/demo.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/demo.py).

Ένα demo του CS2 είναι η δική εγγραφή του διακομιστή (SourceTV): κάθε παίκτης, σε κάθε tick, 64 tick το δευτερόλεπτο
(`TICKRATE = 64`). Διαβάζεται με το [demoparser2](https://github.com/LaihoE/demoparser) σε τρεις κλήσεις, και το
αποτέλεσμα κρατιέται όπως έρχεται, σε ένα `RawPart`:

| Πεδίο | Περιέχει |
|---|---|
| `path` | το αρχείο |
| `map` | το `map_name` από την κεφαλίδα του demo (`de_x`)· κενό αν η κεφαλίδα δεν έχει |
| `samples` | μία γραμμή ανά παίκτη ανά δειγματισμένο tick: τα πεδία παίκτη και κανόνων πιο κάτω, συν `tick`, `steamid`, `name` |
| `events` | όνομα γεγονότος -> οι γραμμές του, με τα πεδία των παικτών με προθέματα `user_`, `attacker_`, `assister_` όπως τα ονομάζει ο αναλυτής |

Τίποτα στο `demo.py` δεν αποφασίζει τι είναι γύρος ή ποιος κέρδισε· αυτό γίνεται στο
[Δημιουργία αγώνα](building-matches.md).

## Τα δειγματισμένα tick {#the-sampled-ticks}

Το `parse_ticks` ζητά τα tick `0, N, 2N, ...` μέχρι 4.000.000 (`LAST_TICK`, πολύ πέρα από κάθε αγώνα - 17 ώρες στα 64
tick το δευτερόλεπτο), όπου *N* είναι το `--every` (προεπιλογή 8). Ο αναλυτής σταματά στο τέλος του demo. Κάθε παίκτης
που υπάρχει σε ένα δειγματισμένο tick δίνει μία γραμμή, είτε ζωντανός, είτε νεκρός, είτε θεατής, είτε coach· το φιλτράρισμα
γίνεται αργότερα.

Το βήμα της δειγματοληψίας σημαίνει περισσότερα από την πυκνότητα του χάρτη: η στιγμή που αποφασίζεται ένας γύρος
διαβάζεται από αυτά τα δείγματα (βλ. [Δημιουργία αγώνα](building-matches.md#rounds)), οπότε οι χρόνοι λήξης των γύρων
είναι ακριβείς μέχρι ένα βήμα (1/8 s από προεπιλογή).

### Πεδία παικτών {#player-fields}

| Ιδιότητα | Γίνεται |
|---|---|
| `X`, `Y`, `Z` | η θέση, σε μονάδες του παιχνιδιού (ίντσες), Z προς τα πάνω. Ο αναλυτής δίνει την αρχή του παίκτη, δηλαδή τα πόδια. |
| `yaw`, `pitch` | η κατεύθυνση του βλέμματος (μοίρες), μετατρέπεται σε μοναδιαίο διάνυσμα |
| `health`, `armor_value` | υγεία, θωράκιση |
| `team_num` | η πλευρά: 2 = T, 3 = CT· οτιδήποτε άλλο (θεατές, 0, 1) δεν είναι πλευρά |
| `team_clan_name` | το όνομα της ομάδας όπως το δείχνει ο διακομιστής, για να ονομαστούν οι ομάδες |
| `active_weapon_name` | το όπλο στο χέρι, όπως το ονομάζει το παιχνίδι (`AK-47`, `Karambit`) |
| `is_alive` | αν ο παίκτης είναι ζωντανός· μόνο οι ζωντανοί παίκτες γίνονται θέσεις |
| `last_place_name` | το όνομα τοποθεσίας του χάρτη (`BombsiteA`) |
| `balance` | τα χρήματα |
| `current_equip_value` | η αξία όσων κουβαλά ο παίκτης |

### Πεδία κανόνων παιχνιδιού {#game-rules-fields}

Διαβάζονται μαζί, μία φορά ανά γραμμή παίκτη (είναι ίδια για όλους σε ένα tick):

| Ιδιότητα | Χρησιμοποιείται για |
|---|---|
| `game_time` | το ρολόι του διακομιστή, σε δευτερόλεπτα |
| `total_rounds_played` | το μέτρημα των γύρων, που συνεχίζει ανάμεσα στα αρχεία ενός αγώνα |
| `round_win_status` | ποιος κέρδισε τον γύρο που μόλις παίχτηκε: 1 ισοπαλία, 2 T, 3 CT |
| `round_win_reason` | πώς (το `CSRoundEndReason` του παιχνιδιού) |
| `team_rounds_total` | το σκορ κάθε πλευράς |
| `is_warmup_period` | το warmup αφήνεται έξω παντού |
| `is_freeze_period` | το πάγωμα αφήνεται έξω από τις θέσεις |
| `CCSGameRulesProxy.CCSGameRules.m_nOvertimePlaying` | η παράταση που παίζεται, 0 στους κανονικούς γύρους: οι γύροι παράτασης δεν είναι γύροι πιστολιού (ο αναλυτής δεν έχει μικρότερο όνομα γι' αυτό) |

## Τα γεγονότα {#the-events}

Κάθε γεγονός πιο κάτω διαβάζεται όταν το demo το δηλώνει (`list_game_events`), με τα `X`, `Y`, `Z`, `team_num`,
`last_place_name` και `which_bomb_zone` (τη ζώνη βόμβας στην οποία βρίσκεται ο παίκτης: 0 καμία, 1 A, 2 B) για κάθε
παίκτη που αναφέρει το γεγονός, και τα `total_rounds_played` και `is_warmup_period` του παιχνιδιού τη στιγμή εκείνη:

| Γεγονός | Γίνεται |
|---|---|
| `player_death` | φόνοι και θάνατοι· χρησιμοποιεί `weapon`, `headshot`, `assistedflash`, `penetrated`, `thrusmoke`, `noscope`, `attackerblind` |
| `player_hurt` | ζημιά· χρησιμοποιεί `dmg_health` (ζημιά που έγινε στην υγεία), `health` (υγεία που απομένει), `weapon` |
| `player_blind` | τυφλωμένοι παίκτες· χρησιμοποιεί `blind_duration` |
| `weapon_fire` | βολές και ρίψεις χειροβομβίδων· χρησιμοποιεί `weapon` |
| `smokegrenade_detonate`, `flashbang_detonate`, `hegrenade_detonate`, `inferno_startburn`, `decoy_detonate` | πού έσκασαν οι χειροβομβίδες· χρησιμοποιεί τα δικά του `x`, `y`, `z` του γεγονότος (το γεγονός δεν έχει όνομα τοποθεσίας για αυτό το σημείο, μόνο για τον ρίχτη) |
| `bomb_planted` | το φύτεμα· χρησιμοποιεί τη `which_bomb_zone` και την τοποθεσία του φυτευτή, και το `site` (ο αριθμός οντότητας της ζώνης) |
| `bomb_defused` | η απενεργοποίηση |
| `bomb_exploded` | πότε εξερράγη η βόμβα: ο χρόνος της γραμμής `explode` |
| `round_freeze_end` | πού αρχίζει κάθε γύρος |
| `round_prestart` | πού τελειώνει ο χρόνος μετά από έναν αποφασισμένο γύρο |
| `round_announce_match_start` | πού αρχίζει ο ζωντανός αγώνας |

## Δύο γεγονότα για demo που καθορίζουν πώς διαβάζονται {#two-facts-about-demos-that-decide-how-they-are-read}

- **Ένας αγώνας μπορεί να είναι χωρισμένος σε αρχεία**, και τα ονόματα των αρχείων δεν λένε τη σειρά τους. Ο αριθμός
  των γύρων (`total_rounds_played`) συνεχίζει ανάμεσά τους, και συνήθως και το ρολόι του διακομιστή, οπότε τα κομμάτια
  μπορούν να μπουν σε σειρά από αυτά που περιέχουν.
- **Μια εγγραφή μπορεί να αρχίσει πριν από τον αγώνα**: warmup, επανεκκίνηση, ένας knife round. Ο αγώνας αρχίζει στο
  **τελευταίο** `round_announce_match_start` ενός αρχείου· πριν από αυτό, όλα αφήνονται έξω, και το warmup αφήνεται έξω
  παντού.
