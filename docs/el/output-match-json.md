# Το έγγραφο αγώνα (`<match>.match.json`) {#the-match-document-matchjson}

Ένα έγγραφο JSON για κάθε αγώνα, δίπλα στον πίνακά του: ομάδες, σκορ, κάθε γύρος με το αποτέλεσμά του, οικονομία,
φύτεμα, φόνοι, clutch και επιζώντες, και η γραμμή σκορ κάθε παίκτη. Είναι αυτό που φορτώνει η καρτέλα **Αγώνας** του
προβολέα του 3DHeat. Κώδικας: η συνάρτηση `summary()` στο
[`heat3d_cs2/stats.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/stats.py)· οι αριθμοί ορίζονται στα
[Στατιστικά](statistics.md).

Το αρχείο είναι UTF-8, με εσοχή ένα κενό, και κρατά τους χαρακτήρες που δεν είναι ASCII (ονόματα παικτών και ομάδων)
όπως είναι. Οι χρόνοι είναι σε δευτερόλεπτα, στρογγυλοποιημένοι σε τρία δεκαδικά για τους γύρους και σε δύο για τους
φόνους και το φύτεμα.

## Το έγγραφο {#the-document}

| Πεδίο | Τύπος | Τι είναι |
|---|---|---|
| `format` | συμβολοσειρά | πάντα `heat3d-cs2-match` - με αυτό αναγνωρίζει ένας αναγνώστης το αρχείο |
| `version` | αριθμός | `3`. Στην έκδοση 1 το `time` ενός φυτέματος ήταν σε δευτερόλεπτα αγώνα· από την 2 είναι δευτερόλεπτα μέσα στον γύρο, όπως ενός φόνου. Η 3 προσθέτει τα πεδία από το `header` και μετά, και το πάγωμα στον πίνακα. |
| `match` | συμβολοσειρά | το όνομα του αγώνα, όπως ονομάζονται τα αρχεία |
| `map` | συμβολοσειρά | ο χάρτης (`de_x`) |
| `demos` | συμβολοσειρά[] | τα αρχεία demo από τα οποία χτίστηκε, μόνο τα ονόματά τους, με τη σειρά του αγώνα |
| `teams` | συμβολοσειρά[] | τα ονόματα των ομάδων με τη σειρά εμφάνισης (γύρος 1: πρώτα η πλευρά T) |
| `score` | αντικείμενο | όνομα ομάδας -> γύροι που κέρδισε: το σκορ του τελευταίου γύρου |
| `winner` | συμβολοσειρά ή null | η ομάδα που κέρδισε τον αγώνα, όπου η εγγραφή δείχνει το τέλος· null για εγγραφή που σταματά νωρίς, για παράταση χωρίς την πινακίδα νίκης, ή για ισοπαλία |
| `winnerSource` | συμβολοσειρά ή null | πώς είναι γνωστός ο `winner`: `winPanel` (η πινακίδα νίκης του αγώνα του παιχνιδιού), `surrender`, `regulation` (περισσότεροι από τους μισούς κανονικούς γύρους) |
| `rounds` | αντικείμενο[] | κάθε πλήρης γύρος, με τη σειρά - [πιο κάτω](#rounds) |
| `incomplete` | αριθμός[] | αριθμοί γύρων που έκοψε το τέλος ενός demo και μένουν έξω |
| `missing` | αριθμός[] | αριθμοί γύρων πριν από τον πρώτο που έχουν τα demo: `[1, 2]` όταν η εγγραφή ξεκινά από τον γύρο 3 |
| `halfLength` | αριθμός ή null | γύροι σε έναν κανονικό ημίχρονο, από το σημείο όπου οι πλευρές αλλάζουν πρώτη φορά (`12` στο σχήμα των 24 γύρων)· null όταν η εγγραφή δεν δείχνει την αλλαγή |
| `pistolRounds` | αριθμός[] | οι γύροι πιστολιού με τους οποίους μετράται το `buy`: ο γύρος 1, και ο γύρος μετά τον ημίχρονο όταν είναι γνωστό το `halfLength`· ποτέ γύρος παράτασης |
| `players` | αντικείμενο[] | η γραμμή σκορ - [πιο κάτω](#players) |
| `conventions` | αντικείμενο | οι ορισμοί πίσω από τους αριθμούς, [πιο κάτω](#conventions) |
| `header` | αντικείμενο | η κεφαλίδα του πρώτου demo όπως την δίνει ο αναλυτής: όνομα διακομιστή, έκδοση patch, έκδοση demo, χάρτης |
| `profiles` | αντικείμενο | Steam ID -> ό,τι μένει σταθερό για έναν παίκτη σε όλο τον αγώνα: `crosshair_code`, `music_kit_id`, `rank`, `comp_wins`, `player_color`, `is_connected` (η τελευταία φορά που φάνηκε) |
| `playerInfo` | αντικείμενο[] | κάθε παίκτης που καταγράφουν τα demo, και οι coach και οι caster: Steam ID, όνομα, αριθμός ομάδας |
| `skins`, `itemDrops` | αντικείμενο[] | skin όπλων και πτώσεις αντικειμένων, όπου τα έχει το demo (τα demo τουρνουά από τη μετάδοση δεν έχουν) |
| `chat` | αντικείμενο[] | κάθε γραμμή συνομιλίας του αγώνα: χρόνος, γύρος, παίκτης, πλευρά, κείμενο |
| `events` | αντικείμενο[] | κάθε γεγονός παιχνιδιού που δεν αφορά κανέναν παίκτη, με σειρά χρόνου, με όλα τα πεδία του: ήχοι γύρου και φάσεις, `round_officially_ended`, `buytime_ended`, `server_message`, `server_cvar` (οι ρυθμίσεις του διακομιστή όπως άλλαξαν), οι λήψεις της κάμερας σκηνοθεσίας της μετάδοσης, `cs_win_panel_match`, ... |
| `state` | αντικείμενο[] | η κατάσταση του παιχνιδιού όπου άλλαξε: χρόνος, πεδίο, τιμή - χρονοκαθυστερήσεις (`is_terrorist_timeout`, `num_ct_timeouts`, `is_technical_timeout`, `is_waiting_for_resume`), η βόμβα (`is_bomb_planted`, `is_bomb_dropped`), `ct_losing_streak` / `t_losing_streak`, `game_phase`, `round_in_progress`, οι παίκτες που είναι ζωντανοί, τα `match_start_time` και `round_start_time` του διακομιστή |
| `selfCheck` | αντικείμενο | `completeness`: πού πήγε καθετί από το demo - ανά όνομα γεγονότος, κλάση ιδιότητας, μήνυμα δικτύου, καρέ και πίνακα συμβολοσειρών, τα πλήθη `seen`, `decoded`, `partial`, `raw` και `lost`, τα βοηθητικά αρχεία που γράφτηκαν, το συνολικό `lost` (0 εκτός αν `--no-bulk`), και οι ιδιότητες που ο αναλυτής τις λέει αλλά δεν μπορεί να τις διαβάσει (`unreadProps`). Η σύμβαση: [Οι μετατροπείς κρατούν τα πάντα](https://github.com/Holdi601/3DHeat/blob/main/docs/converters.md)· τα βοηθητικά αρχεία: η ενότητα Completeness του README |

## Γύροι {#rounds}

| Πεδίο | Τύπος | Τι είναι |
|---|---|---|
| `number` | αριθμός | ο γύρος, από το 1 |
| `start` | αριθμός | δευτερόλεπτα αγώνα όταν τελείωσε το πάγωμα |
| `end` | αριθμός | δευτερόλεπτα αγώνα όταν αποφασίστηκε ο γύρος |
| `until` | αριθμός | δευτερόλεπτα αγώνα όταν ξεκίνησε ο επόμενος γύρος (το τέλος της μετά φάσης) |
| `winner` | συμβολοσειρά | `T` ή `CT`· κενό για ισοπαλία |
| `winnerTeam` | συμβολοσειρά | το όνομα της ομάδας της νικήτριας πλευράς· κενό για ισοπαλία |
| `reason` | συμβολοσειρά | `bomb`, `defuse`, `elimination`, `time`, `surrender`, `draw` ή `other` |
| `score` | αντικείμενο | όνομα ομάδας -> γύροι που κέρδισε μετά από αυτόν |
| `sides` | αντικείμενο | όνομα ομάδας -> `T` / `CT` σε αυτόν τον γύρο |
| `equipment` | αντικείμενο | πλευρά -> συνολική αξία εξοπλισμού των ζωντανών παικτών της στο τέλος του παγώματος, σε δολάρια |
| `buy` | αντικείμενο | πλευρά -> `pistol`, `eco`, `force` ή `full` |
| `plant` | αντικείμενο ή null | το φύτεμα της βόμβας: `site` (`A` ή `B`· κενό όταν το demo δεν το λέει), `time` (δευτερόλεπτα **μέσα στον γύρο**, όπως ενός φόνου), `player`, `steamid`, `x`, `y`, `z` (μονάδες παιχνιδιού), `place` (το όνομα τοποθεσίας του φυτευτή: εκεί που βρισκόταν η βόμβα) |
| `survivors` | αντικείμενο | πλευρά -> ονόματα των αρχικών παικτών που ήταν ακόμα ζωντανοί όταν αποφασίστηκε ο γύρος, ταξινομημένα |
| `clutches` | αντικείμενο[] | καθένα: `player`, `steamid`, `side`, `against` (οι εχθροί που ήταν ζωντανοί όταν ο παίκτης έμεινε τελευταίος), `won` |
| `kills` | αντικείμενο[] | κάθε θάνατος του γύρου, με τη σειρά - πιο κάτω |

Πώς βρίσκονται αυτά: [Δημιουργία αγώνα](building-matches.md#rounds)· clutch και επιζώντες:
[Στατιστικά](statistics.md#clutches).

### Οι φόνοι ενός γύρου {#a-rounds-kills}

Κάθε θάνατος του γύρου, και της μετά φάσης:

| Πεδίο | Τύπος | Τι είναι |
|---|---|---|
| `time` | αριθμός | δευτερόλεπτα **μέσα στον γύρο** (από το τέλος του παγώματος) |
| `attacker`, `attackerSide` | συμβολοσειρά | ο δολοφόνος και η πλευρά του· κενό για τον κόσμο |
| `victim`, `victimSide` | συμβολοσειρά | το θύμα και η πλευρά του |
| `assister` | συμβολοσειρά ή null | ο παίκτης που βοήθησε, ή null |
| `flashAssist` | λογικό | η βοήθεια ήταν φλας |
| `weapon` | συμβολοσειρά | όπως το ονομάζει το παιχνίδι |
| `headshot` | λογικό | |
| `wallbang` | λογικό | η σφαίρα πέρασε από κάτι |
| `throughSmoke` | λογικό | ο φόνος έγινε μέσα από καπνό |
| `noscope` | λογικό | ένα όπλο με σκόπευτρο βγήκε χωρίς σκόπευση |
| `attackerBlind` | λογικό | ο δολοφόνος είχε τυφλωθεί από φλας |
| `opening` | λογικό | ο πρώτος φόνος εχθρού του γύρου |
| `traded` | λογικό | αυτός ο θάνατος εκδικήθηκε μέσα σε 5 s |
| `trade` | λογικό | αυτός ο φόνος εκδίκησε συμπαίκτη μέσα σε 5 s |
| `teamkill` | λογικό | attacker και θύμα στην ίδια πλευρά, δύο διαφορετικοί παίκτες |
| `suicide` | λογικό | attacker και θύμα ο ίδιος παίκτης (μια δική του χειροβομβίδα, για παράδειγμα)· όχι teamkill |
| `after` | λογικό | ο φόνος έγινε αφού είχε αποφασιστεί ο γύρος |
| `place` | συμβολοσειρά | πού ήταν το **θύμα** (το όνομα τοποθεσίας του χάρτη) |

## Παίκτες {#players}

Μία εγγραφή ανά παίκτη, κατά ομάδα και μετά με τον καλύτερο πρώτο, κατά φόνους μείον θανάτους, και μετά κατά φόνους:

| Πεδίο | Τύπος | Τι είναι |
|---|---|---|
| `name`, `steamid`, `team` | συμβολοσειρά | ποιος |
| `kills`, `deaths` | αριθμός | |
| `assists`, `flashAssists` | αριθμός | βοηθείες χωρίς και με φλας |
| `diff` | αριθμός | φόνοι - θάνατοι |
| `adr` | αριθμός | μέση ζημιά ανά γύρο που έπαιξε, υγεία που χάθηκε |
| `kast` | αριθμός | ποσοστό γύρων που έπαιξε με φόνο, βοήθεια, επιβίωση ή εκδικημένο θάνατο |
| `headshotPct` | αριθμός | ποσοστό φόνων που ήταν headshot |
| `openingKills`, `openingDeaths` | αριθμός | μονομαχίες ανοίγματος που κέρδισε και έχασε |
| `tradeKills`, `tradedDeaths` | αριθμός | trade φόνοι· θάνατοι που εκδικήθηκαν |
| `multiKills` | αντικείμενο | `{"2k": n, "3k": n, "4k": n, "5k": n}`: γύροι με τόσους φόνους |
| `clutches`, `clutchesWon` | αριθμός | |
| `utilityDamage` | αριθμός | ζημιά με HE, molotov, incendiary |
| `enemiesFlashed` | αριθμός | εχθροί που τυφλώθηκαν τουλάχιστον 1 s |
| `plants`, `defuses` | αριθμός | |
| `teamkills` | αριθμός | συμπαίκτες που σκοτώθηκαν· οι αυτοκτονίες δεν μετράνε |
| `roundsPlayed` | αριθμός | γύροι που ξεκίνησαν |

Κάθε ορισμός: [Στατιστικά](statistics.md#the-scoreboard-line).

## Συμβάσεις {#conventions}

Γράφονται σε κάθε έγγραφο, ώστε ο αναγνώστης να ξέρει τι σημαίνουν οι αριθμοί χωρίς αυτή τη σελίδα:

```json
"conventions": {
 "tradeSeconds": 5,
 "buy": "pistol: the first round of each regulation half (pistolRounds), none in overtime; else average equipment under $1500 eco, under $4000 force, otherwise full",
 "damage": "health actually lost, enemies only",
 "kast": "rounds with a kill, an assist (flash assists count), survival or a traded death"
}
```
