# Поддържане на страниците {#maintaining-these-pages}

Списъкът за всяка версия. Страниците трябва да казват какво прави кодът, да се четат добре от начинаещ, от 8-годишно дете и от професионалист, и да съществуват на всеки език, който поддържа визуализаторът 3DHeat.

## Списък за версия {#release-checklist}

1. **Регенерирайте генерираните страници** от кода:

   ```bash
   python tools/gen_docs_reference.py
   for f in tools/diagrams/*.json; do python tools/flow2svg.py $f docs/assets/img/$(basename $f .json).svg; done
   ```

   Преди подаване на промените същото с `--check` трябва да завърши с код 0:

   ```bash
   python tools/gen_docs_reference.py --check
   ```

2. **Сравнете функциите от последната версия.** `VERSION` съдържа версията; етикетът ѝ е `v<VERSION>`:

   ```bash
   git log --oneline v$(cat VERSION)..HEAD
   ```

   Всяка нова команда, опция, колона, изход или поведение получава ред на страницата, която го описва, и ред в `CHANGELOG.md` под **Docs**, който назовава страницата.

3. **Независим преглед.** Някой, който не е писал промяната, чете променените страници - включително схемите и картинките - три пъти: като начинаещ (никога не е ползвал терминал), като 8-годишно дете (първият параграф казва ли какво е и защо, с прости думи?) и като професионалист (флаговете, стойностите по подразбиране и колоните точно ли са такива, каквито кодът ги прави?).

4. **Оправете това, което прегледът е открил.** Картинките остават най-много около 900 px широки, с текст поне 12 px, както са показани; схемите се генерират от `tools/diagrams/*.json` с `tools/flow2svg.py`. Примерите използват само измислени имена (`de_x`, "Demo Valley", `<map>`): никога реална карта, играч, номер на мач или фигура от реални файлове.

5. **Преводи.** Всяка преведена страница записва хеша на английския източник, от който е направена. Преведете отново страниците, чийто английски хеш се е променил, и после всеки език се преглежда по същите три начина (прост, начинаещ, професионалист), включително етикетите на схемите.

6. **Публикуване само след одобрение от собственика.** Подавайте локално; собственикът решава кога се публикува.

## Преводите: командите {#translations-the-commands}

Сайтът е преведен на 40-те езика на визуализатора 3DHeat: английският е в `docs/`, всеки друг език е в `docs/<lang>/` със същите имена на файловете. `tools/docs_i18n.py` води отчетността:

```bash
python tools/docs_i18n.py hashes             # след всяка английска промяна: записва хеша на всяка страница
python tools/docs_i18n.py svg-strings        # след всяка промяна на картинка: етикетите за превод
python tools/docs_i18n.py status             # по език: актуални, остарели, липсващи страници
python tools/docs_i18n.py todo --lang de     # немските страници за (пре)превод
python tools/docs_i18n.py svg-build --lang de    # немските картинки от docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # записва английския хеш на немските страници
python tools/docs_i18n.py check              # излиза с 1, когато хешовете или етикетите са стари
```

Превеждайте само това, което `todo` изброява: запазвайте Markdown, връзките, кода, имената на файловете и колоните; превеждайте заглавията и описанията на картинките, и използвайте собствените думи на визуализатора 3DHeat за бутоните и панелите му (`src/i18n/locales/<lang>/`). Генерираните справочни страници и терминалните картинки остават на английски. На сайта остарял превод го казва и дава връзка към английската страница; липсващият пада към английския. Менюто за езици в заглавието и пренасочването по езика на браузъра на началната страница идват от `docs/_includes/`.
