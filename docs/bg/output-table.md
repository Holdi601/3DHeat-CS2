# Топлинната таблица (`<match>.parquet`) {#the-heatmap-table-parquet}

Един Parquet файл на мач: позицията на всеки жив играч, взета на проби, и всяко събитие там, където се е случило - по един ред за всеки. Това е дълга таблица, която визуализаторът 3DHeat чете като топлинна карта, а всеки друг инструмент - като обикновена таблица. Код:
[`heat3d_cs2/output.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/output.py)
(файлът), [`heat3d_cs2/match.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/match.py)
(редовете; вижте [Изграждане на мач](building-matches.md)).

Файлът се записва със Snappy компресия, на групи редове по 256 000 реда. Редовете са подредени по `time`, после по `event`. В него влизат само редовете в рунд (от края на freeze time на рунда до началото на следващия рунд).

На синтетичното демо от тестовете - редовете за събитията на първия рунд:

![редове за събитията в таблицата](../assets/img/table-rows.svg)

В контейнер `.3dheat` таблицата е елементът с роля `table` ([Един файл за мач](output-container.md)).

## Колони {#columns}

Колоните, винаги в този ред. Текстовите колони са низове с речник (`dictionary<int32, string>`) и никога не са null: "няма стойност" е празен низ. Числовите колони са null там, където редът няма стойност.

| Колона | Тип | Какво е |
|---|---|---|
| `match` | низ | името на мача (`alpha-vs-bravo-m1`, или `...-b` за втора верига) |
| `map` | низ | картата от заглавието на демото (`de_x`) |
| `round` | int16 | номерът на рунда, от 1 |
| `roundId` | низ | `<мач> #NN`, номерът на рунда с две цифри (`alpha-vs-bravo-m1 #07`): уникален за всички мачове, сесията на визуализатора |
| `phase` | низ | `freeze` във freeze time на рунда (от края на предишния рунд), `live` до решаването на рунда, `after`, докато победителите търсят и губещите се пазят |
| `time` | float64 | секунди от началото на мача (живото начало на първия му файл), на един общ часовник за всичките му файлове |
| `roundTime` | float32 | секунди от края на freeze time на този рунд; отрицателно във freeze time |
| `event` | низ | какво е редът - вижте [Събития](#събития) |
| `player` | низ | името на играча (за всяко събитие - кой играч е описано по-долу) |
| `steamid` | низ | Steam ID на играча (64-битов, като текст) |
| `side` | низ | `T` или `CT` в този рунд; празно, когато играчът не е бил на страна |
| `team` | низ | името на отбора на играча (или `Started T` / `Started CT`); за `explode` - отборът, поставил бомбата |
| `x`, `y`, `z` | float32 | позиция в собствените координати на играта: инчове (игрови единици), **Z нагоре**, дясна координатна система |
| `dirX`, `dirY`, `dirZ` | float32 | накъде гледа играчът, единичен вектор в същата система; само за позиции |
| `health` | int16 | 0-100; позиции, а при `hurt` - какво е останало след попадението |
| `armor` | int16 | 0-100; позиции, а при `hurt` - какво е останало след попадението |
| `money` | int32 | парите на играча; само позиции |
| `equipment` | int32 | стойността на това, което носи играчът; само позиции |
| `weapon` | низ | оръжието, както го назовава играта (`AK-47`, `M4A1-S`, `Knife` за всяка скин на нож) |
| `place` | низ | собственото име на мястото на картата при позицията на реда (`BombsiteA`, `CTSpawn`); празно при взривяване на граната: демото не назовава място за точката, където е избухнала гранатата |
| `throwerPlace` | низ | името на мястото на хвърлящия, когато гранатата е избухнала; само взривявания на гранати |
| `other` | низ | другият играч при убийство, смърт, попадение или ослепяване |
| `damage` | float32 | загубено здраве; само `hurt` |
| `duration` | float32 | секунди заслепен; само `blind` |
| `headshot` | int8 | 0/1; само `kill` и `death` |
| `opening` | int8 | 0/1, първото убийство на враг в рунда; само `kill` и `death` |
| `traded` | int8 | 0/1. За `kill`: това е било убийство в размяна. За `death`: смъртта е отмъстена в рамките на 5 s. Само `kill` и `death`. |
| `noscope` | int8 | 0/1, убийството е с оръжие с прицел, стреляно без прицел (`noscope` на събитието); само `kill` и `death` |
| `attackerBlind` | int8 | 0/1, убиецът е бил заслепен, когато е убил (`attackerblind` на събитието); само `kill` и `death` |
| `won` | int8 | 0/1, дали страната на този ред е спечелила рунда; null, когато `side` е празно |
| `matchWon` | int8 | 0/1, дали отборът на този ред е спечелил мача; null, когато `team` е празно или записът не показва края (вижте `winner` в документа на мача) |
| `roundEndReason` | низ | как е приключил рундът на реда: `elimination`, `bomb` (бомбата е избухнала), `defuse`, `time`, `surrender`, `draw`, `other` |
| `buy` | низ | покупката на страната на реда в този рунд: `pistol`, `eco`, `force`, `full` |
| `detail` | низ | всяко поле на събитието, което другите колони не носят, като JSON обект (собствените имена на играта): изстрелът на куршумите (`fire_bullets`: начало, ъгли, неточност, разпръскване, индекс на отката, seed...), `dominated`, `revenge`, `attackerinair`, `wipe`... на смърт, `defindex` на предмет, нищо за стъпките |
| `text` | низ | ред от чата; само `chat` |
| `entity` | int32 | същността на гранатата: полетът ѝ при `throw` (редове `grenade`), взривяването ѝ и играчите, които е заслепила, я споделят |
| `hitgroup` | низ | къде е ударил куршумът (`head`, `chest`, ...); `hurt`, `kill`, `death` |
| `armorDamage` | int16 | загубена броня; само `hurt` |
| `hitLocalX`, `hitLocalY`, `hitLocalZ` | float32 | къде по тялото е ударил куршумът, в координатната система на жертвата в метри (x напред, y нагоре от стъпалата, z надясно): лъчът на изстрела (`fire_bullets`, иначе очите и погледът на атакуващия), проследен до тяло, поставено както е стояла и клякала жертвата, до частта, която `hitgroup` назовава; само `hurt` |
| `hitDirX`, `hitDirY`, `hitDirZ` | float32 | посоката на изстрела в същата координатна система; `hitMiss` колко далеч (m) лъчът е минал покрай назованата част (0: през нея); `hitFrom` `bullet` или `aim` |
| `penetrated` | int16 | стени, през които е минал убийственият куршум; `kill` и `death` |
| `throughSmoke` | int8 | 0/1, убит през дим; `kill` и `death` |
| `distance` | float32 | разстоянието на убийството, както го брои играта (метри); `kill` и `death` |
| `assister` | низ | кой е асистирал; `kill` и `death` |
| `flash`, `flashAlpha` | float32 | останали секунди на блясъка и колко е бял; позиции |
| `helmet`, `defuser`, `scoped`, `walking`, `airborne`, `buyZone`, `bombZone`, `defusing`, `spotted` | int8 | 0/1; позиции |
| `zoom`, `duck`, `moveType` | | нивото на мащабиране на прицела, колко е клекнал (0-1), видът движение на играта; позиции |
| `spottedBy` | низ | Steam ID на враговете, които виждат този играч, разделени с `\|`; позиции |
| `inventory` | низ | всичко, което играчът носи, разделено с `\|`; позиции |
| `ammo`, `ammoReserve`, `shotsFired` | int16 | пълнителят и резервът на оръжието в ръка; изстрелите в текущия откос; позиции |
| `punchPitch`, `punchYaw` | float32 | ударът на отката върху прицела, в градуси; позиции |
| `ping` | int16 | милисекунди; позиции |
| `killsTotal`, `deathsTotal`, `assistsTotal`, `headshotKillsTotal`, `damageTotal`, `utilityDamageTotal`, `enemiesFlashedTotal`, `objectiveTotal`, `aceRoundsTotal`, `threeKillRoundsTotal`, `aliveTimeTotal`, `moneySavedTotal`, `mvps`, `score` | int | собствените броения на играта за таблото до момента в мача; позиции |
| `cashSpent`, `cashSpentTotal`, `roundStartEquipment` | int32 | похарчените пари в този рунд и в мача; стойността на екипировката, когато рундът е започнал; позиции |
| `state_helmet`, `state_defuser`, `state_kevlar`, `state_scoped`, `state_flashed` | int8 | 0/1, състоянието на играча във времето на реда, включително събитията: каска, комплект за обезвреждане, каквато и да е броня, с прицел (от последната проба на позиция на играча до реда), заслепен (вътре в `blind`, който го е ударил); всеки ред, който назовава играч |
| `state_utility` | int16 | носените във времето гранати (от `inventory`); всеки ред, който назовава играч |
| `state_weapon` | низ | оръжието в ръка във времето (при `death` - на жертвата, където `weapon` е на убиеца); всеки ред, който назовава играч |
| `earn_round_cs2` | int16 | какво е платил рундът: при `round_end` наградата за победа или бонуса за загуба (с бонуса на поставилата страна), при `plant` и `defuse` - 300 на играча |

## Събития {#events}

Кой играч назовава реда, къде стои и кои колони запълва.
`match`, `map`, `round`, `roundId`, `phase`, `time`, `roundTime`, `event`,
`won`, `roundEndReason` и `buy` са запълнени на всеки ред (`matchWon`, когато е известен победителят на мача); `inventory`, `money`, `equipment` и
колоните `state_*` - на всеки ред, който назовава играч (събитията ги вземат от последната проба на позиция на играча).

| `event` | `player` / `side` / `team` | `x`, `y`, `z` | Също запълнени |
|---|---|---|---|
| `position` | играчът | играчът (стъпалата) | `dirX`-`dirZ`, `health`, `armor`, `money`, `equipment`, `weapon` (в ръка), `place` и цялото състояние на играча (колоните от `flash` нататък) - включително във freeze time |
| `kill` | убиецът | където е стоял убиецът | `other` (жертвата), `weapon`, `headshot`, `opening`, `traded` (убийство в размяна), `noscope`, `attackerBlind`, `place` |
| `death` | жертвата | където е паднала жертвата | `other` (убиецът; празно за света), `weapon`, `headshot`, `opening`, `traded` (отмъстена), `noscope`, `attackerBlind`, `place` |
| `hurt` | жертвата | където е ударена жертвата | `other` (атакуващият), `damage`, `health`, `armor`, `armorDamage`, `hitgroup`, `weapon`, `place` - включително попаденията по съотборници и от света |
| `shot` | стрелецът | откъде е стреляно | `weapon`, `place`, `detail` (сметката на играта за куршумите) |
| `slash` | играчът | където е замахнат с нож | `weapon` = `Knife` |
| `grenade` | хвърлящият | гранатата в полет, по пробите на играчите и там, където е спряла | `weapon` (гранатата), `entity` |
| `throw` | хвърлящият | откъде е хвърлена гранатата | `weapon` (гранатата), `place` |
| `smoke`, `flash`, `he`, `molotov`, `decoy` | хвърлящият | където е избухнала | `weapon`, `throwerPlace` (мястото на хвърлящия в този момент); `place` остава празно |
| `blind` | заслепеният играч | където е стоял | `other` (хвърлилият блясъка), `duration`, `weapon` = `Flashbang`, `entity`, `place` - включително заслепени съотборници |
| `plant` | поставящият | където е поставил | `weapon` = `C4 Explosive`, `place`, `earn_round_cs2` (300) |
| `defuse` | обезвреждащият | където е обезвредил | `weapon` = `C4 Explosive`, `place`, `earn_round_cs2` (300) |
| `round_end` | всеки играч, който е играл рунда | където играчът е стоял последно | `won`, `earn_round_cs2` (какво е платил рундът на играча: ръста на парите на страната до следващия freeze time, където правилата го позволяват, иначе собственото им правило), `detail` (`winner`, `reason`, `lossBonus`, `plant`) |
| `explode` | поставящият (със своя Steam ID), страна `T`, отборът, който е поставил | позицията на поставянето | `weapon` = `C4 Explosive`, `place` (на поставящия при поставянето: където е лежала бомбата); времето му е, когато бомбата е избухнала |
| `chat` | изпращачът | където е бил | `text` |
| всяко друго игрово събитие за играч, под името на играта: `item_pickup`, `item_equip`, `player_footstep`, `player_jump`, `weapon_reload`, `weapon_zoom`, `player_spawn`, `bomb_beginplant`, `bomb_begindefuse`, `bomb_dropped`, `bomb_pickup`, `bomb_exploded`, `smokegrenade_expired`, `inferno_expire`, `decoy_started`, `player_team`, `player_disconnect`, ... | играчът | където е бил (при събитие на граната: където е била тя) | `weapon` (на предмет), `entity`, `detail` (всяко поле на събитието) |

Какво има и какво не:

- Редовете **position** са живи играчи на страна, извън freeze time и загряване, на всеки `--every` тика (по подразбиране осем в секунда).
- Редовете **kill** са само убийства от враг - без teamkill, самоубийство или смърт от света. Редовете **death** са всяка смърт, включително тях.
- Редовете **explode** са всяка поставена бомба, която е избухнала, по `bomb_exploded` на демото: включително в след фазата, когато Т вече са спечелили с елиминиране. Демо без това събитие получава по един за всеки рунд, спечелен от бомбата, в края на рунда.
- Редовете **hurt** и **blind** са само между врагове.
- **shot** пропуска ножовете и C4; гранатите са редове **throw**.
- **molotov** обхваща молотовите и запалителните (започването на огъня).
- Щетите по съотборници, блясъците на съотборници и наблюдатели, събитията от freeze time и всичко между рундовете не са в таблицата.

Работен пример, от синтетичното демо от тестовете (хвърлен дим, първо убийство в главата, размени):

| time | roundTime | event | player | side | x | y | weapon | other | damage | headshot | opening | traded |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 18.75 | 8.75 | throw | ash | T | 120 | 10 | Smoke Grenade | | | | | |
| 19.84 | 9.84 | hurt | bob | CT | -500 | -300 | AK-47 | ace | 60 | | | |
| 20.00 | 10.00 | death | bob | CT | -500 | -300 | AK-47 | ace | | 1 | 1 | 1 |
| 20.00 | 10.00 | hurt | bob | CT | -500 | -300 | AK-47 | ace | 40 | | | |
| 20.00 | 10.00 | kill | ace | T | 100 | 0 | AK-47 | bob | | 1 | 1 | 0 |
| 20.16 | 10.16 | smoke | ash | T | 50 | 60 | Smoke Grenade | | | | | |
| 21.88 | 11.88 | death | ace | T | 100 | 0 | AK-47 | ben | | 0 | 0 | 1 |

## Подсказките `heat3d` в футъра {#the-heat3d-footer-hints}

Футърът на Parquet файла (метаданните на схемата) носи инструкции за четене под ключа **`heat3d`**, JSON обект:

```json
{
  "version": 1,
  "kind": "cs2-demo",
  "axes": {"up": "z", "flipX": false, "flipY": true, "flipZ": false, "scale": 1},
  "entity": {"size": 32},
  "columns": {
    "x": "x", "y": "y", "z": "z",
    "time": "time", "timeUnit": "seconds",
    "personId": "player",
    "teamId": "side",
    "sessionId": "roundId",
    "lookMode": "vector", "dirX": "dirX", "dirY": "dirY", "dirZ": "dirZ",
    "extra": ["event", "match", "round", "roundTime", "phase", "weapon", "place", "won", "matchWon", "roundEndReason", "buy", "opening", "team", ...]
  }
}
```

| Запис | Казва |
|---|---|
| `version`, `kind` | версията на подсказките (1) и какво ги е записало (`cs2-demo`) |
| `axes.up` | Z на файла е нагоре |
| `axes.flipY` | обърни знака на Y на файла (вижте по-долу) |
| `axes.scale` | 1: позициите се ползват както са, в игрови единици |
| `entity.size` | играч е **32 единици** широк - ширината на играча в CS2 - размерът, с който повторение с кутии нарисува един |
| `columns.x` / `y` / `z` | колоните на позицията |
| `columns.time`, `timeUnit` | `time`, в секунди |
| `columns.personId` | играчът е личността |
| `columns.teamId` | страната е групата (така T и CT, а не имената на отборите, оцветяват групите) |
| `columns.sessionId` | всеки рунд (`roundId`) е сесия |
| `columns.lookMode` и `dirX`-`dirZ` | посоката на погледа е вектор в тези колони |
| `columns.extra` | колоните, които се пазят за филтриране, по ред на полезност |

Визуализатор, който знае ключа, отваря файла без да се настройва нищо. Всичко друго пренебрегва ключа. За да го прочетете сами:

```python
import json
import pyarrow.parquet as pq

table = pq.read_table("out/de_x/alpha-vs-bravo-m1.parquet")
hints = json.loads(table.schema.metadata[b"heat3d"])
rows = table.to_pandas()
kills = rows[rows["event"] == "kill"]
```

## Оси и единици {#axes-and-units}

Координатите са на самата игра: **инчове** (една игрова единица; играч е 72 единици висок, когато стои, и 32 широк), **Z нагоре** и дясна координатна система.

Визуализатор, чийто свят е с Y нагоре, трябва да чертае координатите на играта (x, y, z) като **(x, z, -y)** - Z става височината, а Y е с обратен знак. Това е завъртане, не огледало. Ако се чертае като ляво-ориентиран свят с Z нагоре, (x, z, y), всяка карта излиза огледално, сайт A - от грешната страна; `flipY: true` е това, което подсказките казват да се предотврати. [Експортът на карта](map-export.md) записва геометрията си вече в координатната система (x, z, -y), в същите единици, така че лежи под таблицата без никаква корекция.

Разстоянията във визуализатора са означени в метри; при мащаб 1 те са игрови единици. Умножете по 0.0254 за метри.

## Размер {#size}

Позициите доминират: около десет играча x 8 проби в секунда живо време на играта при подразбиращото се `--every 8`, по-малко за мъртвите играчи и freeze time. Намаляването наполовина на `--every` удвоява тях; събитията не се променят.
