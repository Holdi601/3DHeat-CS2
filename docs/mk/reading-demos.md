# Читање демо {#reading-a-demo}

Што се вади од една датотека `.dem`, пред да се толкува што било. Код:
[`heat3d_cs2/demo.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/demo.py).

Демото на CS2 е сопствената снимка на серверот (SourceTV): секој играч, секој
такт, 64 тактови во секунда (`TICKRATE = 64`). Се чита со
[demoparser2](https://github.com/LaihoE/demoparser) во три повици, а
резултатот се чува каков што доаѓа, во `RawPart`:

| Поле | Содржи |
|---|---|
| `path` | датотеката |
| `map` | `map_name` од заглавието на демото (`de_x`); празно ако заглавието нема |
| `samples` | еден ред по играч по семплиран такт: полињата на играчот и на правилата подолу, плус `tick`, `steamid`, `name` |
| `events` | име на настан -> неговите редови, со полињата на играчите со префикси `user_`, `attacker_`, `assister_` како што ги именува парсерот |

Ништо во `demo.py` не одлучува што е рунда или кој победил; тоа е
[Составување на натпревар](building-matches.md).

## Семплираните тактови {#the-sampled-ticks}

На `parse_ticks` му се бараат тактовите `0, N, 2N, ...` до 4.000.000
(`LAST_TICK`, далеку над кој било натпревар - 17 часа на 64 тактови во секунда),
каде *N* е `--every` (стандардно 8). Парсерот запира на крајот на демото.
Секој играч присутен на семплиран такт дава еден ред, без разлика дали е жив,
мртов, гледач или тренер; филтрирањето се прави подоцна.

Чекорот на семплирање е важен и надвор од густината на топлинската мапа:
моментот кога рундата е одлучена се чита од овие примероци (видете
[Составување на натпревар](building-matches.md#rounds)), па времињата на крајот на
рундите се точни до еден чекор (стандардно 1/8 s).

### Полиња на играчот {#player-fields}

| Својство | Станува |
|---|---|
| `X`, `Y`, `Z` | позицијата, во единици на играта (инчи), Z нагоре. demoparser2 го дава потеклото на играчот, т.е. стопалата. |
| `yaw`, `pitch` | насоката на гледање (степени), претворена во единечен вектор |
| `health`, `armor_value` | здравје, оклоп |
| `team_num` | страната: 2 = T, 3 = CT; сè друго (гледачи, 0, 1) не е страна |
| `team_clan_name` | името на тимот како што го покажува серверот, се користи за именување на тимовите |
| `active_weapon_name` | држеното оружје, како што го именува играта (`AK-47`, `Karambit`) |
| `is_alive` | дали играчот е жив - само живите играчи стануваат позиции |
| `last_place_name` | сопственото име на местото на мапата (`BombsiteA`) |
| `balance` | пари |
| `current_equip_value` | вредноста на она што го носи играчот |

### Полиња на правилата на играта {#game-rules-fields}

Се читаат заедно, еднаш по ред на играч (исти се за сите на еден такт):

| Својство | Се користи за |
|---|---|
| `game_time` | часовникот на серверот, во секунди |
| `total_rounds_played` | бројот на рунди, што продолжува низ датотеките на натпреварот |
| `round_win_status` | кој ја добил тукушто одиграната рунда: 1 нерешено, 2 T, 3 CT |
| `round_win_reason` | како (`CSRoundEndReason` на играта) |
| `team_rounds_total` | резултатот на секоја страна |
| `is_warmup_period` | загревањето се изоставува насекаде |
| `is_freeze_period` | замрзнатото време се изоставува од позициите |
| `CCSGameRulesProxy.CCSGameRules.m_nOvertimePlaying` | продолжението што се игра, 0 во регуларното време: рундите од продолжението не се пиштолски (парсерот нема пократко име за него) |

## Настаните {#the-events}

Секој настан подолу се чита кога демото го декларира (`list_game_events`), со
`X`, `Y`, `Z`, `team_num`, `last_place_name` и `which_bomb_zone` (зоната за
бомба во која стои играчот: 0 ниедна, 1 A, 2 B) за секој играч што го именува
настанот, и `total_rounds_played` и `is_warmup_period` на играта во тој такт:

| Настан | Станува |
|---|---|
| `player_death` | убиства и смрти; користи `weapon`, `headshot`, `assistedflash`, `penetrated`, `thrusmoke`, `noscope`, `attackerblind` |
| `player_hurt` | штета; користи `dmg_health` (штета нанесена на здравјето), `health` (преостанато здравје), `weapon` |
| `player_blind` | заслепени играчи; користи `blind_duration` |
| `weapon_fire` | истрели и фрлања на гранати; користи `weapon` |
| `smokegrenade_detonate`, `flashbang_detonate`, `hegrenade_detonate`, `inferno_startburn`, `decoy_detonate` | каде гранатите експлодирале; ги користи сопствените `x`, `y`, `z` на настанот (настанот нема име на место за таа точка, само за фрлачот) |
| `bomb_planted` | поставувањето; користи `which_bomb_zone` и местото на поставувачот, и `site` (бројот на ентитетот на зоната) |
| `bomb_defused` | деактивирањето |
| `bomb_exploded` | кога експлодирала бомбата: времето на редот `explode` |
| `round_freeze_end` | каде почнува секоја рунда |
| `round_prestart` | каде завршува времето по одлучена рунда |
| `round_announce_match_start` | каде почнува живиот натпревар |

## Два факта за демоата што одлучуваат како се читаат {#two-facts-about-demos-that-decide-how-they-are-read}

- **Натпреварот може да е поделен на датотеки**, а имињата на датотеките не го
  кажуваат нивниот редослед. Бројот на рунди (`total_rounds_played`)
  продолжува низ нив, и обично и часовникот на серверот, па деловите можат да
  се наредат според она што го содржат.
- **Снимката може да почне пред натпреварот**: загревање, рестарт, рунда со ножеви.
  Натпреварот почнува на **последниот** `round_announce_match_start` во датотеката;
  пред него сè се изоставува, а загревањето се изоставува насекаде.
