# Табелата за топлинска мапа (`<match>.parquet`) {#the-heatmap-table-parquet}

Една Parquet датотека по натпревар: позицијата на секој жив играч, семплирана, и
секој настан таму каде што се случил, по еден ред - долга табела што
прегледувачот 3DHeat ја чита како топлинска мапа, а секој друг како обична
табела. Код:
[`heat3d_cs2/output.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/output.py)
(датотеката), [`heat3d_cs2/match.py`](https://github.com/Holdi601/3DHeat-CS2/blob/main/heat3d_cs2/match.py)
(редовите; видете [Составување на натпревар](building-matches.md)).

Датотеката се пишува со Snappy компресија во групи од 256.000 реда. Редовите
се подредени по `time`, потоа по `event`. Во неа има само редови внатре во
рунда (од крајот на нејзиното замрзнато време до почетокот на следната рунда).

На синтетичкото демо од тестовите, редовите на настани од првата рунда:

![редови на настани од табелата](../assets/img/table-rows.svg)

Во контејнер `.3dheat` табелата е членот со улога `table`
([Една датотека по натпревар](output-container.md)).

## Колони {#columns}

Колоните, секогаш по овој редослед. Текстуалните колони се низи кодирани со
речник (`dictionary<int32, string>`) и никогаш не се null: „нема вредност“ е
празна низа. Нумеричките колони се null таму каде што редот нема вредност.

| Колона | Тип | Што |
|---|---|---|
| `match` | string | името на натпреварот (`alpha-vs-bravo-m1`, или `...-b` за втор синџир) |
| `map` | string | мапата, од заглавието на демото (`de_x`) |
| `round` | int16 | бројот на рундата, од 1 |
| `roundId` | string | `<match> #NN`, бројот на рундата со две цифри (`alpha-vs-bravo-m1 #07`): уникатен низ натпреварите, сесијата на прегледувачот |
| `phase` | string | `freeze` во замрзнатото време на рундата (од крајот на претходната рунда), `live` додека рундата не е одлучена, `after` додека победниците ловат, а губитниците спасуваат |
| `time` | float64 | секунди од почетокот на натпреварот (живиот почеток на неговата прва датотека), на еден часовник низ неговите датотеки |
| `roundTime` | float32 | секунди од крајот на замрзнатото време на оваа рунда; негативно во замрзнатото време |
| `event` | string | што е редот - видете [Настани](#events) |
| `player` | string | името на играчот (за секој настан, кој играч е кажано подолу) |
| `steamid` | string | Steam ID на играчот (64-битен, како текст) |
| `side` | string | `T` или `CT` во оваа рунда; празно кога играчот не бил на ниту една страна |
| `team` | string | името на тимот на играчот (или `Started T` / `Started CT`); за `explode`, тимот што поставува |
| `x`, `y`, `z` | float32 | позиција во сопствените координати на играта: инчи (единици на играта), **Z нагоре**, десен систем |
| `dirX`, `dirY`, `dirZ` | float32 | каде гледа играчот, единечен вектор во истиот координатен систем; само позиции |
| `health` | int16 | 0-100; позиции, и на `hurt` она што останало по ударот |
| `armor` | int16 | 0-100; позиции, и на `hurt` она што останало по ударот |
| `money` | int32 | парите на играчот; само позиции |
| `equipment` | int32 | вредноста на она што го носи играчот; само позиции |
| `weapon` | string | оружјето како што го именува играта (`AK-47`, `M4A1-S`, `Knife` за секоја облека на нож) |
| `place` | string | сопственото име на местото на мапата на позицијата на редот (`BombsiteA`, `CTSpawn`); празно на детонации на гранати: демото не именува место за таму каде што граната експлодирала |
| `throwerPlace` | string | името на местото на фрлачот кога гранатата експлодирала; само детонации на гранати |
| `other` | string | другиот играч во убиство, смрт, удар или блесок |
| `damage` | float32 | изгубено здравје; само `hurt` |
| `duration` | float32 | секунди заслепување; само `blind` |
| `headshot` | int8 | 0/1; само `kill` и `death` |
| `opening` | int8 | 0/1, првото убиство на непријател во рундата; само `kill` и `death` |
| `traded` | int8 | 0/1. За `kill`: било убиство-размена. За `death`: била осветена во рок од 5 s. Само `kill` и `death`. |
| `noscope` | int8 | 0/1, убиството е со оружје со оптика пукано без оптика (`noscope` од настанот); само `kill` и `death` |
| `attackerBlind` | int8 | 0/1, убиецот бил заслепен кога убил (`attackerblind` од настанот); само `kill` и `death` |
| `won` | int8 | 0/1, дали страната на овој ред ја добила рундата; null кога `side` е празно |
| `matchWon` | int8 | 0/1, дали тимот на овој ред го добил натпреварот; null кога `team` е празно или снимката не го покажува крајот (видете `winner` во документот на натпреварот) |
| `roundEndReason` | string | како завршила рундата на редот: `elimination`, `bomb` (бомбата експлодирала), `defuse`, `time`, `surrender`, `draw`, `other` |
| `buy` | string | набавката на страната на овој ред во оваа рунда: `pistol`, `eco`, `force`, `full` |
| `detail` | string | секое поле од настанот што другите колони не го носат, како JSON објект (имиња на играта): куршумите на истрелот (`fire_bullets`: потекло, агли, неточност, расејување, индекс на трзај, seed...), `dominated`, `revenge`, `attackerinair`, `wipe`... на смрт, `defindex` на предмет, на чекор ништо |
| `text` | string | линија од чет; само `chat` |
| `entity` | int32 | ентитетот на гранатата: летот на `throw` (редови `grenade`), нејзината детонација и играчите што ги заслепила го делат |
| `hitgroup` | string | каде погодил куршумот (`head`, `chest`, ...); `hurt`, `kill`, `death` |
| `armorDamage` | int16 | изгубен оклоп; само `hurt` |
| `hitLocalX`, `hitLocalY`, `hitLocalZ` | float32 | каде на телото погодил куршумот, во координатниот систем на жртвата во метри (x напред, y нагоре од стопалата, z десно): зракот на истрелот (`fire_bullets`, инаку окото и погледот на напаѓачот) следен до тело поставено како што стоела и клекнувала жртвата, до делот што го именува `hitgroup`; само `hurt` |
| `hitDirX`, `hitDirY`, `hitDirZ` | float32 | насоката на истрелот во истиот координатен систем; `hitMiss` колку (m) зракот го промашил именуваниот дел (0: низ него); `hitFrom` `bullet` или `aim` |
| `penetrated` | int16 | ѕидови низ кои поминал смртоносниот куршум; `kill` и `death` |
| `throughSmoke` | int8 | 0/1, убиен низ чад; `kill` и `death` |
| `distance` | float32 | растојанието на убиството како што го брои играта (метри); `kill` и `death` |
| `assister` | string | кој асистирал; `kill` и `death` |
| `flash`, `flashAlpha` | float32 | преостанати секунди блесок, и колку бел; позиции |
| `helmet`, `defuser`, `scoped`, `walking`, `airborne`, `buyZone`, `bombZone`, `defusing`, `spotted` | int8 | 0/1; позиции |
| `zoom`, `duck`, `moveType` | | нивото на зум на оптиката, колку клекнато (0-1), типот на движење на играта; позиции |
| `spottedBy` | string | Steam ID-ата на непријателите што го гледаат овој играч, разделени со `\|`; позиции |
| `inventory` | string | сè што го носи играчот, разделено со `\|`; позиции |
| `ammo`, `ammoReserve`, `shotsFired` | int16 | шаржерот и резервата на држеното оружје; истрели во тековната серија; позиции |
| `punchPitch`, `punchYaw` | float32 | ударот на нишанот од трзајот, степени; позиции |
| `ping` | int16 | милисекунди; позиции |
| `killsTotal`, `deathsTotal`, `assistsTotal`, `headshotKillsTotal`, `damageTotal`, `utilityDamageTotal`, `enemiesFlashedTotal`, `objectiveTotal`, `aceRoundsTotal`, `threeKillRoundsTotal`, `aliveTimeTotal`, `moneySavedTotal`, `mvps`, `score` | int | сопствените бројки од табелата со резултати на играта за натпреварот досега; позиции |
| `cashSpent`, `cashSpentTotal`, `roundStartEquipment` | int32 | потрошени пари во оваа рунда и во натпреварот; вредност на опремата кога почнала рундата; позиции |
| `state_helmet`, `state_defuser`, `state_kevlar`, `state_scoped`, `state_flashed` | int8 | 0/1, состојбата на играчот во времето на редот, настаните вклучени: шлем, комплет за деактивирање, каков било оклоп, со оптика (од последниот примерок на позиција на играчот до редот), заслепен (внатре во `blind` што го погодил); секој ред што именува играч |
| `state_utility` | int16 | гранати што се носат во тоа време (од `inventory`); секој ред што именува играч |
| `state_weapon` | string | оружјето во рака во тоа време (на `death`, на самата жртва, додека `weapon` е на убиецот); секој ред што именува играч |
| `earn_round_cs2` | int16 | што платила рундата: на `round_end` наградата за победа или бонусот за загуба (со бонусот на страната што поставува), на `plant` и `defuse` 300 на играчот |

## Настани {#events}

Кој играч го именува редот, каде стои, и кои колони ги пополнува.
`match`, `map`, `round`, `roundId`, `phase`, `time`, `roundTime`, `event`,
`won`, `roundEndReason` и `buy` се пополнети на секој ред (`matchWon` каде што
победникот на натпреварот е познат); `inventory`, `money`, `equipment` и колоните
`state_*` на секој ред што именува играч (настаните ги земаат од последниот
примерок на позиција на играчот).

| `event` | `player` / `side` / `team` | `x`, `y`, `z` | Исто така пополнето |
|---|---|---|---|
| `position` | играчот | играчот (стопала) | `dirX`-`dirZ`, `health`, `armor`, `money`, `equipment`, `weapon` (држено), `place`, и целата состојба на играчот (колоните од `flash` натаму) - и во замрзнатото време |
| `kill` | убиецот | каде стоел убиецот | `other` (жртвата), `weapon`, `headshot`, `opening`, `traded` (убиство-размена), `noscope`, `attackerBlind`, `place` |
| `death` | жртвата | каде паднала жртвата | `other` (убиецот; празно за светот), `weapon`, `headshot`, `opening`, `traded` (осветена), `noscope`, `attackerBlind`, `place` |
| `hurt` | жртвата | каде била погодена жртвата | `other` (напаѓачот), `damage`, `health`, `armor`, `armorDamage`, `hitgroup`, `weapon`, `place` - и ударите на соиграчи и на светот |
| `shot` | стрелецот | од каде е пукано | `weapon`, `place`, `detail` (описот на куршумите од играта) |
| `slash` | играчот | каде е замавнат нож | `weapon` = `Knife` |
| `grenade` | фрлачот | гранатата во лет, на семплирањето на играчите и таму каде што запрела | `weapon` (гранатата), `entity` |
| `throw` | фрлачот | од каде е фрлена гранатата | `weapon` (гранатата), `place` |
| `smoke`, `flash`, `he`, `molotov`, `decoy` | фрлачот | каде експлодирала | `weapon`, `throwerPlace` (местото на фрлачот во тој момент); `place` останува празно |
| `blind` | заслепениот играч | каде стоел | `other` (оној што фрлил блесок), `duration`, `weapon` = `Flashbang`, `entity`, `place` - и заслепените соиграчи |
| `plant` | поставувачот | каде поставил | `weapon` = `C4 Explosive`, `place`, `earn_round_cs2` (300) |
| `defuse` | деактивирачот | каде деактивирал | `weapon` = `C4 Explosive`, `place`, `earn_round_cs2` (300) |
| `round_end` | секој играч што ја играл рундата | каде играчот стоел последен пат | `won`, `earn_round_cs2` (што рундата им платила: пораст на парите на страната до следното замрзнато време каде што правилата дозволуваат, инаку сопствената вредност од правилата), `detail` (`winner`, `reason`, `lossBonus`, `plant`) |
| `explode` | поставувачот (со неговиот Steam ID), страна `T`, тимот што поставува | позицијата на поставувањето | `weapon` = `C4 Explosive`, `place` (на поставувачот при поставувањето: каде лежела бомбата); неговото време е кога експлодирала бомбата |
| `chat` | испраќачот | каде бил | `text` |
| секој друг настан на играта за играч, под името на играта: `item_pickup`, `item_equip`, `player_footstep`, `player_jump`, `weapon_reload`, `weapon_zoom`, `player_spawn`, `bomb_beginplant`, `bomb_begindefuse`, `bomb_dropped`, `bomb_pickup`, `bomb_exploded`, `smokegrenade_expired`, `inferno_expire`, `decoy_started`, `player_team`, `player_disconnect`, ... | играчот | каде бил (настаните на граната: каде била) | `weapon` (на предметот), `entity`, `detail` (секое поле од настанот) |

Што е внатре и што не:

- Редовите **position** се живи играчи на страна, надвор од замрзнатото
  време и загревањето, на секои `--every` тактови (осум во секунда стандардно).
- Редовите **kill** се само убиства од непријател - без убиство на свој,
  самоубиство или смрт од светот. Редовите **death** се секоја смрт, и тие
  вклучени.
- Редовите **explode** се секоја поставена бомба што експлодирала, според
  `bomb_exploded` од демото: и во after фазата, кога T веќе победиле со
  елиминација. Демо без тој настан добива еден за секоја рунда добиена со
  бомбата, на крајот на рундата.
- Редовите **hurt** и **blind** се само меѓу непријатели.
- **shot** ги изоставува ножевите и C4; гранатите се редови **throw**.
- **molotov** ги покрива молотовите и запаливите (почетокот на огнот).
- Штетата на соиграчи, блесоците на соиграчи и гледачи, настаните од
  замрзнатото време и сè меѓу рундите не се во табелата.

Работен пример, од синтетичкото демо од тестовите (фрлен чад, отворачко
убиство со хедшот, размени):

| time | roundTime | event | player | side | x | y | weapon | other | damage | headshot | opening | traded |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 18.75 | 8.75 | throw | ash | T | 120 | 10 | Smoke Grenade | | | | | |
| 19.84 | 9.84 | hurt | bob | CT | -500 | -300 | AK-47 | ace | 60 | | | |
| 20.00 | 10.00 | death | bob | CT | -500 | -300 | AK-47 | ace | | 1 | 1 | 1 |
| 20.00 | 10.00 | hurt | bob | CT | -500 | -300 | AK-47 | ace | 40 | | | |
| 20.00 | 10.00 | kill | ace | T | 100 | 0 | AK-47 | bob | | 1 | 1 | 0 |
| 20.16 | 10.16 | smoke | ash | T | 50 | 60 | Smoke Grenade | | | | | |
| 21.88 | 11.88 | death | ace | T | 100 | 0 | AK-47 | ben | | 0 | 0 | 1 |
| 21.88 | 11.88 | kill | ben | CT | -520 | -320 | AK-47 | ace | | 0 | 0 | 1 |

Смртта на bob е осветена со убиството на ace од ben 1,9 s подоцна (редот
`death` на bob: traded 1; редот `kill` на ben: убиство-размена, traded 1);
вториот удар врз bob беше штета 137 на здравје 40, па брои 40.

## Навестувањата `heat3d` во подножјето {#the-heat3d-footer-hints}

Подножјето на Parquet датотеката (метаподатоци клуч/вредност на шемата) носи
упатства за читање под клучот **`heat3d`**, JSON објект:

```json
{
  "version": 1,
  "kind": "cs2-demo",
  "axes": {"up": "z", "flipX": false, "flipY": true, "flipZ": false, "scale": 1},
  "entity": {"size": 32},
  "columns": {
    "x": "x", "y": "y", "z": "z",
    "time": "time", "timeUnit": "seconds",
    "personId": "player",
    "teamId": "side",
    "sessionId": "roundId",
    "lookMode": "vector", "dirX": "dirX", "dirY": "dirY", "dirZ": "dirZ",
    "extra": ["event", "match", "round", "roundTime", "phase", "weapon", "place", "won", "matchWon", "roundEndReason", "buy", "opening", "team", ...]
  }
}
```

| Запис | Кажува |
|---|---|
| `version`, `kind` | верзијата на навестувањата (1) и што ги напишало (`cs2-demo`) |
| `axes.up` | Z на датотеката е нагоре |
| `axes.flipY` | го негира Y на датотеката (видете подолу) |
| `axes.scale` | 1: позициите се користат како што се, во единици на играта |
| `entity.size` | играчот е широк **32 единици** - ширината на играч во CS2 - големината со која го црта репризата со кутија |
| `columns.x` / `y` / `z` | колоните на позицијата |
| `columns.time`, `timeUnit` | `time`, во секунди |
| `columns.personId` | играчот е лицето |
| `columns.teamId` | страната е групата (па T и CT, не имињата на тимовите, ги бојадисуваат групите) |
| `columns.sessionId` | секоја рунда (`roundId`) е сесија |
| `columns.lookMode` и `dirX`-`dirZ` | насоката на гледање е вектор во тие колони |
| `columns.extra` | колоните што се чуваат како филтри, по редослед на корисност |

Прегледувач што го знае клучот ја отвора датотеката без ништо да подесува.
Сè друго го игнорира. За да го прочитате сами:

```python
import json
import pyarrow.parquet as pq

table = pq.read_table("out/de_x/alpha-vs-bravo-m1.parquet")
hints = json.loads(table.schema.metadata[b"heat3d"])
rows = table.to_pandas()
kills = rows[rows["event"] == "kill"]
```

## Оски и единици {#axes-and-units}

Координатите се сопствените на играта: **инчи** (една единица на играта;
играчот е висок 72 единици стоејќи и широк 32), **Z нагоре**, и десен систем.

Прегледувач чиј свет е со Y нагоре мора да го црта (x, y, z) на играта како
**(x, z, -y)** - Z станува висината, а Y се негира. Тоа е ротација, не
огледало. Нацртано онака како што се црта левороктен свет со Z нагоре, како
(x, z, y), секоја мапа излегува огледална, местото A на погрешна страна;
`flipY: true` е она што навестувањата го кажуваат за да се спречи тоа.
[Извозот на мапа](map-export.md) ја пишува својата геометрија веќе во
координатниот систем (x, z, -y), во исти единици, па лежи под табелата без
никакво прилагодување.

Растојанијата во прегледувачот се означени во метри; со размер 1 тие се
единици на играта. Помножете со 0,0254 за метри.

## Големина {#size}

Позициите доминираат: околу десет играчи x 8 примероци во секунда жива игра
со стандардниот `--every 8`, помалку за мртви играчи и замрзнато време.
Преполовувањето на `--every` ги удвојува; настаните не се засегнати.
